# Spec: Post TOC scroll-spy + active section highlight

- Date: 2026-03-06 16:33 (Asia/Shanghai)
- Slug: toc-scrollspy

## User story
As a reader, when I scroll through an article, I want the TOC (目录) to automatically highlight the current section so I can quickly understand where I am and jump to nearby sections.

## Scope
Add client-side behavior for post pages that already render a TOC (`.toc-nav`):
1) Highlight the TOC link for the heading currently in view (scroll-spy).
2) When clicking a TOC link, smoothly scroll to the target heading.
3) Keep accessibility in mind (use `aria-current="true"` on the active TOC link).

## Acceptance criteria
- On a post page with a TOC, scrolling updates the active TOC item:
  - exactly one TOC link has `.is-active` and `aria-current="true"` when a heading is active.
  - when above the first heading, the first TOC item is active.
  - when at/near the bottom, the last heading becomes active.
- Clicking a TOC link performs a smooth scroll (where supported) and still works without JS.
- No errors on pages without a TOC.
- Adds minimal CSS so the active TOC item is visually distinct.

## Non-goals / boundaries
- Do not change Hexo markdown rendering or server-side TOC generation.
- Do not add new UI surfaces beyond styling the existing TOC.
- No dependency on external libraries.
