# Related Posts Feature Spec

## Feature Name
Related Posts (基于标签的相关文章推荐)

## Description
在文章底部显示相关文章列表，基于标签相似度计算。帮助用户发现更多相关内容，提升阅读体验和页面停留时间。

## User Requirements
- 作为读者，在阅读完一篇文章后，想快速找到相似主题的文章
- 作为访客，希望相关文章推荐准确且有吸引力
- 作为作者，希望提升内容的可发现性和页面浏览量

## Acceptance Criteria

### Core Functionality
- [x] 在文章页底部显示"相关文章"区域
- [x] 基于标签计算文章相似度（至少共享1个标签）
- [x] 按相似度排序显示相关文章（共享标签数越多越靠前）
- [x] 最多显示 5 篇相关文章
- [x] 如果没有相关文章，隐藏该区域

### UI Requirements
- [x] 显示文章标题
- [x] 显示文章发布日期
- [x] 显示共享的标签（前3个）
- [x] 鼠标悬停时有视觉反馈
- [x] 响应式设计（移动端友好）
- [x] 支持中英文双语

### Edge Cases
- [x] 文章没有标签时不显示相关文章区域
- [x] 只有一篇标签文章时不显示相关文章区域（或显示"暂无相关文章"）
- [x] 当前文章不出现在相关文章列表中
- [x] 已发布但未来的文章不推荐

### Performance
- [x] 使用 Hexo 插件生成静态数据（无需客户端计算）
- [x] 相关文章数据在构建时预计算，避免运行时开销

## Technical Implementation

### Data Structure
在文章对象中添加 `relatedPosts` 数组：
```javascript
{
  title: "Article Title",
  path: "2024/01/01/example/",
  date: "2024-01-01",
  tags: ["tag1", "tag2"],
  relatedPosts: [
    { title: "Related 1", path: "...", sharedTags: ["tag1"], score: 1 },
    { title: "Related 2", path: "...", sharedTags: ["tag1", "tag2"], score: 2 }
  ]
}
```

### Components
1. **Hexo Helper/Plugin**: 构建时计算所有文章的相关文章
2. **Template**: 文章页底部显示相关文章列表
3. **CSS**: 样式和布局
4. **Test**: 单元测试验证相似度计算逻辑

### Algorithm
1. 获取当前文章的所有标签
2. 遍历所有其他文章
3. 计算共享标签数（intersection）
4. 按共享标签数降序排序
5. 取前 5 篇
6. 过滤掉未发布的文章
