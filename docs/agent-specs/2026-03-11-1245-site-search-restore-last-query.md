# Spec: Site Search 记住并恢复上一次查询（restore last query）

- Date: 2026-03-11 12:45 (Asia/Shanghai)
- Slug: site-search-restore-last-query

## 背景 / 问题
站内搜索弹窗每次打开都会清空输入框。用户经常需要反复打开搜索（例如阅读多篇文章时），希望能够延续上一次搜索词，减少重复输入。

## 需求
在站内搜索（Site Search modal）中：
1) 关闭搜索弹窗时，将当前输入框的查询词保存到 localStorage。
2) 再次打开弹窗时：
   - 若保存的查询词非空，则自动填充到输入框，并自动触发一次搜索渲染（等同于用户手动输入）。
   - 若保存的查询词为空/不存在，则保持现有行为（空输入，展示默认提示/建议）。
3) 当用户在弹窗打开状态下按 ESC 且输入框非空触发“清空输入框”行为时，同时清空保存的查询词（避免下次又恢复出来）。

## 验收标准
- 用户关闭弹窗后再次打开：输入框展示上一次的查询词。
- 打开后无需手动输入即可看到对应的搜索结果（或标签模式结果）。
- 在弹窗内按 ESC 清空输入框后，关闭并再次打开不应恢复之前的查询词。
- 不影响现有快捷键打开（/、Cmd+K、Ctrl+K）、键盘导航与 recent history 功能。

## 边界 / 非目标
- 不新增跨设备同步；仅同一浏览器 localStorage。
- 不改变“recent queries（最近搜索）”的记录逻辑（仍以用户打开结果为准）。
- 不引入新的依赖。

## 实现提示
- 新增 storage key：`xdlkc:site-search:last`。
- 写入策略：在 `handleClose()` 关闭前写入；在 ESC 清空输入时写入空字符串。
- 恢复策略：在 `handleOpen()` 内读取并填充，随后 dispatch `input` 事件以复用既有搜索逻辑（含 ensureDb）。
