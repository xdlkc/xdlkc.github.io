# Spec: 代码块复制按钮与复制成功提示（Code Copy Button with Success Feedback）

- Date: 2026-03-17 10:43 (Asia/Shanghai)
- Slug: code-copy-button

## 背景 / 问题
用户在阅读技术博客时，经常需要复制代码块中的代码到本地运行或测试。当前博客没有复制按钮，用户需要：
- 手动选中代码
- 使用右键菜单或快捷键复制
- 容易选中不完整（漏掉行号或开头/结尾）
- 体验不够流畅

用户期望一个一键复制代码的功能，并有清晰的反馈确认复制成功。

## 需求
为所有代码块添加复制按钮，提供流畅的复制体验：

### R1. 复制按钮位置和样式
- 在每个代码块右上角显示复制按钮
- 使用通用的复制图标（📋或icon）
- 按钮悬停时高亮，有hover效果
- 在移动端和桌面端都可用
- 打印时不显示复制按钮

### R2. 复制功能
- 点击复制按钮时，复制代码块中的纯文本内容
- 不复制行号（如果代码块有行号）
- 成功复制后，按钮图标变为✓或显示"已复制"
- 2秒后恢复原状
- 如果复制失败（如权限问题），显示错误提示

### R3. 支持的代码块格式
- Hexo highlight代码块（`<figure class="highlight">`）
- 行内代码（`<code>`）不添加复制按钮
- Fenced code块（如果主题支持）

### R4. 无障碍性
- 复制按钮有`aria-label`："复制代码"
- 使用`type="button"`避免表单提交
- 键盘可访问（Tab键可聚焦）
- 复制成功后通过ARIA状态通知屏幕阅读器

### R5. 性能和兼容性
- 使用现代Clipboard API（`navigator.clipboard.writeText`）
- 降级方案：如果Clipboard API不可用，使用`document.execCommand('copy')`
- 不影响页面加载性能
- 不依赖外部库

## 验收标准
1. 所有代码块右上角都有复制按钮
2. 点击按钮能正确复制代码内容（不包含行号）
3. 复制成功后按钮显示成功状态，2秒后恢复
4. 复制失败时显示错误提示
5. 打印时不显示复制按钮
6. 移动端和桌面端都能正常使用
7. 键盘导航可以访问复制按钮
8. 新增测试文件 `tests/code-copy-button.test.js`
9. 新增JS文件 `js/code-copy.js`
10. `layout.ejs` 或 `post.ejs` 引入 `code-copy.js`
11. `npm test` 全部通过

## 边界 / 不做
- 不实现代码块折叠/展开功能
- 不添加语法高亮（已有功能）
- 不添加复制历史记录
- 不添加一键运行代码功能
- 不修改代码块本身的样式（只添加复制按钮）
