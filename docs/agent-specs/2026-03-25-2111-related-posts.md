# Related Posts (Tags/Keywords)
## Requirement
Add a feature to compute related posts dynamically based on shared tags, or alternatively shared keywords in the title, with an optional fallback to recent posts. The calculation must be case-insensitive for tags.

## Acceptance Criteria
- Computes related posts by shared tags, matching case-insensitively.
- Excludes the current post.
- If tags are absent, matches by shared title keywords.
- Supports a fallback to recent posts if no related matches are found and the fallback option is enabled.
- Passes all unit tests in `tests/related-posts-helper.test.js`.

## Boundary Conditions
- Gracefully handles empty or null tags.
- Fallback works correctly even if all other posts have no tags.
- Post itself is never included in the related list.
