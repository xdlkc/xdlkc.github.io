# Spec: 文章元信息新增字数统计

## 背景
当前文章页已经展示了发布日期、更新时间与预计阅读时长，但缺少字数规模信息。读者在决定是否阅读时，字数是一个直观参考。

## 需求
在文章页元信息中新增“字数”展示，格式为：`字数 <number>`。

## 验收标准
1. 新增 Hexo helper：`post_word_count(content)`，可对文章 HTML 内容统计字数。
2. 统计规则：
   - 中文字符（`\u4E00-\u9FFF`）按 1 字计数；
   - 非中文文本按空白分词后，每个英文/数字 token 按 1 计数；
   - 先去除 HTML 标签；
   - 空内容返回 0。
3. 文章页 `themes/evan/layout/post.ejs` 在“预计阅读 X 分钟”后追加“ · 字数 N”。
4. 新增自动化测试覆盖中文、英文、空内容与 HTML 去标签场景。

## 边界与非目标
- 不引入多语言单位切换；
- 不做更复杂的自然语言分词（如日文假名、emoji 特殊权重）；
- 仅改文章页，不改列表页。
