# 功能迭代：文章页自动 TOC（目录）的平滑滚动与当前项高亮

## 需求

用户在文章页面点击自动生成的目录（TOC）中的链接时，页面应平滑滚动到对应的标题位置。同时，当用户滚动页面时，目录中当前在视口内的标题对应的项目应被高亮显示，以提供更好的阅读导航体验。

## 验收标准

1.  **平滑滚动:**
    *   在文章页面，点击 TOC 中的任意 H2 或 H3 标题链接。
    *   页面应以动画形式（平滑地）滚动到目标标题的顶部，而不是瞬时跳转。
    *   滚动结束后，目标标题应清晰可见，且不被顶部固定元素（如导航栏）遮挡（需要考虑一个小的偏移量）。

2.  **当前项高亮:**
    *   当用户滚动文章内容时，TOC 中与当前视口内可见的最高级别标题对应的项目应被添加一个 `active` 类（例如，`toc-item-active`）。
    *   当用户滚动到下一个标题区域时，旧的 `active` 类应被移除，新的当前标题对应的项目应被高亮。
    *   如果页面顶部没有任何标题可见（例如在文章顶部或底部），则 TOC 中不应有任何高亮项（或者高亮文章标题本身）。

## 边界

*   **浏览器兼容性:** 目标支持现代浏览器（Chrome, Firefox, Safari, Edge 最新版本）。
*   **CSS 样式:** 仅关注 JavaScript 逻辑实现。具体的 `active` 类样式（如颜色、背景）由 CSS 定义，不在本次迭代范围内。
*   **滚动偏移:** 需要考虑页面顶部是否存在固定导航栏或 header，导致锚点内容被遮挡的问题。通过 JavaScript 计算合适的滚动偏移量来解决。
*   **多级目录:** 仅支持 H2 和 H3 标题的 TOC，并能正确处理其层级关系。
*   **性能:** 滚动监听逻辑应具有良好的性能，避免在频繁滚动时造成页面卡顿。
