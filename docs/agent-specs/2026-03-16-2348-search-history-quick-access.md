# 搜索历史记录与快速访问

## 需求描述

为站内搜索功能添加搜索历史记录，用户可以快速访问之前的搜索查询，提升搜索体验。

## 功能范围

### 核心功能

1. **搜索历史保存**
   - 每次执行搜索后，自动保存查询到本地存储
   - 最多保存最近10条搜索记录
   - 去重：相同的查询只保留最新的一次

2. **搜索历史展示**
   - 在搜索框下方显示最近搜索历史
   - 每条历史记录显示查询文本和搜索时间（相对时间，如"5分钟前"）
   - 点击历史记录可以快速填充搜索框并触发搜索

3. **搜索历史管理**
   - 提供"清除历史"按钮，一键清除所有历史记录
   - 历史记录持久化到 localStorage，关闭浏览器后仍然保留

### 边界条件

1. **不保存的情况**
   - 空查询不保存
   - 只有实际产生搜索结果或显示无结果状态时才保存
   - 标签查询（#tag）和分类查询（cat:xxx）都应该保存

2. **展示时机**
   - 当搜索框获得焦点时显示历史记录
   - 当搜索框失去焦点时隐藏历史记录
   - 当用户开始输入新内容时，历史记录被搜索结果覆盖

3. **隐私考虑**
   - 仅保存在用户的浏览器本地（localStorage）
   - 不发送到服务器
   - 每个站点使用独立的localStorage key

## 验收标准

1. 搜索后，查询被正确保存到localStorage
2. localStorage中最多保存10条记录
3. 相同查询重复搜索时，只保留最新记录（移动到顶部）
4. 点击历史记录项，搜索框被填充并触发搜索
5. 点击"清除历史"按钮，所有历史记录被删除
6. 历史记录在页面刷新后仍然存在
7. 空查询不会被保存到历史记录

## 实现细节

### 数据结构

```javascript
{
  query: "search text",
  timestamp: 1710633600000,
  count: 3  // 可选：搜索次数统计
}
```

### localStorage key

`xdlkc:search-history`

### UI元素

- `[data-site-search-history]` - 历史记录容器
- `[data-site-search-history-item]` - 单条历史记录
- `[data-site-search-history-clear]` - 清除历史按钮
- `[data-site-search-history-empty]` - 空历史状态

### 优先级

- P0: 核心保存和展示功能
- P1: 搜索次数统计、时间显示优化
- P2: 高级筛选和导出功能

## 不包含的功能

- 跨设备同步历史记录
- 搜索建议（不同于历史记录）
- 搜索统计和分析
- 历史记录的编辑和标注
