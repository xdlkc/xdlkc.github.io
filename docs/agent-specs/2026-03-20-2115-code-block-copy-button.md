# 功能规格：代码块复制按钮与复制成功提示

## 1. 需求背景
提升用户在阅读技术文章时的体验，方便其复制文章中的代码片段，减少手动选择和复制的麻烦，并提供操作反馈。

## 2. 功能描述
在博客文章页面的每个代码块（`<pre><code>...</code></pre>`）右上角添加一个“复制”按钮。当用户点击该按钮时，代码块内容将被复制到剪贴板，并且按钮文字或图标会临时变为“已复制”或显示一个成功提示，持续短时间后恢复原状。

## 3. 验收标准
- **用户界面**:
    - 每个代码块的右上角应显示一个清晰可见的“复制”按钮或图标。
    - 按钮/图标在不同屏幕尺寸和设备上（响应式设计）应正确显示且不影响代码块布局。
    - 按钮应有视觉反馈（如hover效果）。
- **核心功能**:
    - 点击“复制”按钮后，对应的代码块内容（纯文本，不含行号等装饰）能准确复制到用户的剪贴板。
    - 复制操作完成后，按钮应在短时间内（例如2-3秒）显示“已复制”提示。
    - 提示消失后，按钮恢复到初始状态（“复制”文字或图标）。
- **兼容性**:
    - 在主流浏览器（Chrome, Firefox, Safari, Edge）上功能正常。
- **性能**:
    - 功能的添加不应显著影响页面加载速度和渲染性能。
- **可访问性**:
    - 按钮应可通过键盘聚焦和激活。

## 4. 边界与限制
- **代码块类型**: 仅针对 `<pre><code>` 标签包裹的代码块。
- **内容格式**: 复制时只获取代码块的纯文本内容，不包括行号、语言标识或其他由CSS或JS添加的装饰性元素。
- **错误处理**: 如果复制失败（例如浏览器不支持Clipboard API或权限问题），应有静默处理或提供简短错误提示（可选）。
- **依赖**: 尽量使用原生JavaScript或现有轻量级库，避免引入大型框架。

## 5. 技术实现考虑
- 使用 `Clipboard API` 进行复制操作。
- 动态查找所有代码块，并为每个代码块注入按钮。
- CSS 样式控制按钮位置和提示效果。
- 事件监听处理点击事件。
