# Spec: RSS XSLT Styling (RSS 输出增强)

## Objective
Enhance the RSS feed output by adding an XSLT stylesheet so it renders cleanly and readable in browsers, improving the user experience for non-reader apps.

## TDD Plan
1. Create a test `tests/ui/rss.test.js` checking if `rss.xml` generated includes `<?xml-stylesheet type="text/xsl" href="/rss.xsl"?>`.
2. Add `source/rss.xsl` containing basic RSS styling.
3. Update `_config.yml` to point to a custom template `themes/evan/layout/rss2.xml`.
4. Copy default `rss2.xml` to `themes/evan/layout/rss2.xml` and insert `<?xml-stylesheet type="text/xsl" href="/rss.xsl"?>` after the XML declaration.
