# Spec: 站内搜索结果展示发布日期

- 时间：2026-03-07 22:34 (Asia/Shanghai)
- 目标：让站内搜索结果更“可扫读”，用户能直接看到文章发布日期。

## 需求

当用户打开站内搜索并输入关键词后：
1. 每条搜索结果除标题/标签外，额外展示该文章的发布日期（YYYY-MM-DD）。
2. 若某条记录缺少日期字段，则不渲染日期区域（不显示空占位）。

## 验收标准

- 在搜索结果列表中，存在日期文本（例如：`2026-03-01`）。
- 日期展示不影响现有的标题高亮与标签展示。
- 无日期的记录仍可正常渲染与点击。
- `npm test`（node --test）全量通过。

## 边界/不做

- 不新增筛选/排序规则（仍沿用当前 score 逻辑）。
- 不做复杂的本地化日期格式（仅输出 YYYY-MM-DD）。
- 不修改 db.json 生成逻辑（仅消费已有字段）。
