# Spec: 阅读指标排除代码块内容

## 背景
当前文章页展示“预计阅读分钟”和“字数”。当文章包含大量代码示例时，代码中的 token 会被计入统计，导致阅读时长和字数偏高，影响读者对正文阅读成本的判断。

## 需求
- 阅读时长与字数统计应忽略以下 HTML 节点中的文本：
  - `<pre>...</pre>`（代码块）
  - `<code>...</code>`（行内代码）
- 其他正文内容保持现有统计规则（中文按字、非中文按空白分词）。

## 验收标准
1. `countPostWords()` 对仅包含代码块的内容返回 `0`。
2. `estimateReadingMinutes()` 对仅包含代码块的内容返回最小值 `1`（保持当前下限规则）。
3. 对“正文 + 代码”的混合内容，仅统计正文部分，不统计代码部分。
4. 现有非代码场景测试保持通过。

## 边界与非目标
- 不做 AST 级 Markdown 解析，仅基于生成后的 HTML 做规则处理。
- 暂不区分不同语言代码块，也不引入可配置开关。
- 不调整现有阅读速度参数（中文 300 字/分钟，英文 200 词/分钟）。
