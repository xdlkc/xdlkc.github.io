# Spec: 打印按钮功能

- Date: 2026-03-18 03:35 (Asia/Shanghai)
- Slug: print-optimization

## 背景 / 问题
用户可能需要打印博客文章进行离线阅读或存档。当前博客的打印样式和元数据已经完善，但是缺少一个便捷的打印按钮。用户需要手动使用浏览器的打印菜单（Ctrl/Cmd+P），不够直观。

用户期望有一个明显的打印按钮，可以快速调用浏览器的打印功能。

## 需求
为博客文章添加打印按钮功能：

### R1. 打印按钮
- 在文章页面添加打印按钮（位置：文章标题下方，与其他按钮如"行号"、"复制链接"并排）
- 按钮文本：中英文切换（"打印"/"Print"）
- 按钮有清晰的 `aria-label`（"打印此文章"/"Print this article"）
- 点击按钮时调用浏览器的打印功能（`window.print()`）

### R2. 用户体验
- 打印按钮与其他按钮样式一致，视觉上协调
- 支持键盘操作（Tab 键聚焦，Enter/Space 键触发）
- 响应语言切换（中英文文本自动更新）

## 验收标准
1. 打印按钮出现在文章页面的标题下方（与其他按钮并排）
2. 点击打印按钮可以调用浏览器打印功能
3. 打印按钮有正确的 `aria-label` 和中英文文本
4. 支持键盘操作（Tab、Enter、Space）
5. 响应语言切换事件（中英文文本自动更新）
6. 新增测试文件 `tests/print-button.test.js`
7. `npm test` 全部通过

## 边界 / 不做
- 不修改现有的 print.css 文件（打印样式已完善）
- 不修改打印元数据的实现（已存在）
- 不添加 PDF 导出功能（只使用浏览器原生打印）
- 不修改打印对话框的行为
