# Spec: Page 页面自动 TOC（目录）与锚点导航

- Date: 2026-03-10 09:26 (Asia/Shanghai)
- Slug: page-toc

## 背景 / 问题
当前站点的文章页（post）已经提供 TOC（桌面侧边栏 + 移动端折叠）与滚动高亮导航，但普通页面（page，如 About/News 等）只有正文，没有目录。

当页面内容较长或包含多个小节时，用户难以快速跳转定位。

## 需求
为 **page 布局页面** 添加与 post 页一致的「自动 TOC（目录）与锚点导航」能力：

- 当页面正文存在 H2/H3/H4 时：
  - 桌面端显示右侧 TOC 卡片（`.toc-card` + `.toc-nav`）
  - 移动端在正文前显示折叠 TOC（`details.toc-mobile`）
  - 启用 toc-scrollspy：滚动时高亮当前小节；点击目录平滑跳转（由现有脚本负责）
- 当页面无可用目录时：不渲染 TOC 相关 DOM（避免空占位）

## 验收标准
1. `themes/evan/layout/page.ejs` 使用 `toc(page.content, { class: 'toc-nav', max_depth: 3, list_number: false })` 生成 TOC。
2. 当 TOC 非空时：页面包含移动端 `details.toc-mobile` 与桌面侧边 `aside.toc-card` 两套入口。
3. `page.ejs` 引入 `/js/toc-scrollspy.js` 并在页面加载后调用 `TocScrollSpy?.initTocScrollSpy()`。
4. `npm test` 全部通过。

## 边界 / 非目标
- 不改动 post.ejs 的 TOC 结构与行为。
- 不新增样式体系：复用现有 `.toc-card/.toc-nav/.toc-mobile` 样式。
- 不保证所有自定义 HTML 片段都能生成 TOC（仅依赖 Hexo `toc()` helper 的输出与现有脚本的 auto-generate 逻辑）。
