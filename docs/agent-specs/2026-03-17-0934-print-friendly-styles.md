# Spec: 打印样式优化（Print-Friendly Styles）

- Date: 2026-03-17 09:34 (Asia/Shanghai)
- Slug: print-friendly-styles

## 背景 / 问题
当前博客在打印文章时，会打印所有页面元素（导航栏、侧边栏、按钮等），导致：
- 浪费纸张和墨水
- 打印的文档包含无关元素（导航、搜索按钮等）
- 打印排版不美观，难以阅读

用户需要打印文章以便离线阅读时，希望得到干净、专注的文档。

## 需求
为博客添加打印样式优化，使打印输出更加友好：

### R1. 打印时隐藏的元素
- 导航栏（`.article-nav`）
- 返回顶部按钮
- 分享按钮（`.article-share`）
- 文章链接复制按钮（`.article-link-copy`）
- 点赞按钮（`.post-like`）
- 评论区域（`.post-comments`）
- 上一篇/下一篇导航（`.post-navigation`）
- TOC 目录（桌面端和移动端）
- Related Posts 区域
- 搜索按钮、主题切换、字体切换等所有交互按钮
- 阅读进度条（`.reading-progress`）

### R2. 打印时保留的元素
- 文章标题
- 文章元数据（发布日期、阅读时间、字数）
- 文章正文
- 文章中的图片和代码块
- 版权信息（如果存在）

### R3. 打印排版优化
- 移除背景色和图片背景，减少墨水使用
- 使用黑白色，移除彩色元素
- 优化字体大小，保证可读性
- 代码块保持语法高亮（可选），或改为单色
- 链接显示 URL（可选），便于后续访问
- 调整边距，充分利用纸张空间
- 图片适配宽度，避免溢出

### R4. 打印元数据
- 在页面底部添加打印信息：文章标题、URL、打印日期
- 确保用户知道文章的来源和打印时间

## 验收标准
1. 新增 CSS 文件 `themes/evan/source/css/print.css`
2. `layout.ejs` 引入 `print.css`（使用 `<link rel="stylesheet" media="print">`）
3. 打印预览时，导航栏、按钮等交互元素被隐藏
4. 打印预览时，文章正文清晰可读，排版美观
5. 打印预览时，页面底部显示文章元数据（标题、URL、打印日期）
6. 现有屏幕显示不受影响
7. `npm test` 全部通过

## 边界 / 不做
- 不改变屏幕显示样式
- 不添加打印按钮（用户使用浏览器打印功能）
- 不实现打印时的页眉页脚自定义（使用浏览器默认）
- 不实现分页控制（使用浏览器默认分页）
