# Spec: Related Posts (相关阅读)

- Date: 2026-03-06 15:33 (Asia/Shanghai)
- Slug: related-posts

## Goal / User Value
On every article page, show a small **“相关阅读 / Related Posts”** section to help readers continue exploring similar content.

## Requirements
1. **Only on post pages** (`layout: post`).
2. The section appears **below the article content**.
3. Related posts are computed by **tag overlap**:
   - Score = number of shared tags between current post and candidate post.
   - Candidates with score `0` are excluded.
4. **Sorting**:
   1) Higher score first
   2) If tie: newer `date` first
   3) If still tie: stable by `path` (lexicographic)
5. **Limit**: show up to `6` posts.
6. **Safety/Edge cases**:
   - If the current post has no tags, or no candidates match, the section is not rendered.
   - The current post itself must be excluded.
   - Should work when tags are objects (`{ name }`) or plain strings.

## Acceptance Criteria
- Given a mocked set of posts with tags, the helper returns the expected post order and excludes non-matching posts.
- `themes/evan/layout/post.ejs` renders a `related-posts` section that loops through the computed posts.
- `npm test` passes.

## Non-goals / Boundaries
- No full-text similarity, TF-IDF, or keyword embedding.
- No new pages, no RSS changes, no SEO schema changes in this iteration.
- No cross-language stemming.
