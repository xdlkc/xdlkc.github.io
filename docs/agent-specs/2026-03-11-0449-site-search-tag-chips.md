# Spec: 站内搜索支持“标签芯片”一键切换为标签搜索

## 背景/动机
当前站内搜索已支持 `#tag` 或 `tags:xxx` 的标签搜索模式，但用户需要手动输入语法；并且搜索结果里展示的标签是纯文本，无法直接点击继续探索。

本次做一个“小而完整、用户可感知”的增强：
- 在搜索结果中，文章标签以可点击的 chip 形式展示；点击后自动把输入框切换为 `#标签` 并立即触发搜索。
- 在空查询时展示的“热门标签”chips 也改为标签模式（点击后填入 `#标签`）。

## 需求
1. 搜索结果条目中的每个 tag 以 `<button>` chip 展示（可聚焦、可点击），并带 `data-site-search-keyword`。
2. tag chip 点击后：
   - 搜索输入框值设置为 `#<tag>`（若 tag 本身已以 `#` 开头则不重复添加）。
   - 触发一次 `input` 事件，使搜索结果立即刷新。
3. 空查询时的“热门标签”chips 同样使用标签模式（点击后填入 `#<tag>`）。
4. 不改变现有普通关键词 chips（例如无结果时的拆分关键词 chips、最近搜索 chips）：这些 chips 仍按普通关键词填入，不自动加 `#`。

## 验收标准
- 在 jsdom 测试中：渲染含 tags 的搜索结果后，点击某个 tag chip 会把输入框值变为 `#AI`，且会触发一次 `input` 事件。
- 在 jsdom 测试中：空查询时的热门标签 chip 点击后同样写入 `#AI`。

## 边界/非目标
- 不做搜索算法/排序的大改动。
- 不新增外部依赖。
- 样式仅做最小必要调整，保证按钮外观与现有 tag 样式一致且可点击。
