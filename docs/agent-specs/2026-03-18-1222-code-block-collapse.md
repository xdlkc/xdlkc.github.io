# Code Block Collapse Feature

## 需求

为文章页面的代码块添加折叠/展开功能，允许用户隐藏过长的代码块，提高阅读体验。

## 背景

当文章包含大量代码时，过长的代码块会占用大量页面空间，影响阅读体验。添加折叠功能可以让用户在不需要时隐藏代码块，需要时再展开查看。

## 验收标准

1. 每个代码块（`figure.highlight` 或 `pre.highlight`）顶部添加一个折叠/展开按钮
2. 点击按钮可以切换代码块的显示/隐藏状态
3. 折叠状态下，代码块高度限制为约 5-10 行，底部显示渐变遮罩提示
4. 展开状态下，代码块完整显示
5. 状态持久化到 localStorage，记住用户的折叠偏好
6. 复制按钮仍然在折叠状态下可见和可用
7. 支持键盘快捷键（c 键）折叠/展开当前代码块

## 边界条件

- 如果代码块内容少于 10 行，不显示折叠按钮
- 移动端默认折叠代码块，桌面端默认展开
- 当用户复制代码时，自动展开代码块
- 代码块标题/语言标签仍然可见

## 实现方案

1. 在 `themes/evan/source/js/code-collapse.js` 中创建折叠模块
2. 在代码块顶部添加折叠按钮 UI
3. 使用 CSS 实现折叠状态的视觉效果（高度限制 + 渐变遮罩）
4. 添加点击和键盘事件处理
5. 使用 localStorage 持久化状态
6. 在 post.ejs 中引入脚本

## 测试用例

1. 折叠按钮只在代码块内容超过 10 行时显示
2. 点击折叠按钮切换代码块的显示/隐藏状态
3. 状态正确保存到 localStorage
4. 复制代码时自动展开代码块
5. 键盘快捷键 c 可以折叠/展开当前代码块
6. 移动端默认折叠，桌面端默认展开
