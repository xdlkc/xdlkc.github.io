# Spec: 文章图片点击打开原图（SDD + TDD）

- Created: 2026-03-08 06:34 (Asia/Shanghai)
- Slug: image-open

## 需求 / Why

文章里经常会插入截图或长图。当前主题下图片为纯展示，用户想看清细节需要手动右键/长按。希望提供一个“可感知、轻量”的交互：点击正文图片即可打开原图。

## 用户故事

- 作为读者，我在文章正文看到一张图时，点击它能在新标签页打开原图，方便放大查看。

## 验收标准（必须满足）

1. 仅对文章正文区域 `.article-content img` 生效。
2. 若图片本身已被链接包裹（`<a><img/></a>`），不劫持点击（保持原有跳转行为）。
3. 点击图片会调用 `window.open(img.src, '_blank', 'noopener')`（或等价实现），避免 opener 注入。
4. 为可感知性：符合条件的图片会设置 `cursor: zoom-in`（通过 data attribute 或 class 实现）。
5. 代码需同时支持浏览器运行与 Node 测试环境（CommonJS 导出）。

## 边界 / Non-goals

- 不实现 lightbox/遮罩层/轮播。
- 不处理懒加载占位图与 srcset 选择逻辑（使用点击时的 `img.currentSrc || img.src`）。
- 不修改 Markdown 渲染器输出。

## 测试策略

- 单元测试（jsdom）：
  - 未被链接包裹的图片：点击会触发 window.open，且 url 为图片 currentSrc/src。
  - 被 `<a>` 包裹的图片：点击不会触发 window.open。
  - init 后图片带有标记属性（用于 cursor 样式）。
