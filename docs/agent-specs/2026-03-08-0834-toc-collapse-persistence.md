# Spec: TOC 折叠状态持久化（跨页面记忆）

## 背景 / 目标
当前文章页 TOC 支持对含子标题的条目进行折叠/展开，但刷新页面或打开另一篇文章后折叠状态会丢失。

目标：**记住用户对 TOC 子标题的折叠/展开操作**，在同一浏览器内跨页面保持一致，提升阅读长文体验。

## 需求
1. 当用户点击 TOC 条目的折叠按钮（`.toc-collapse-btn`）后：
   - 折叠状态立即生效（现有行为保持不变）
   - 将该条目的折叠状态写入 `localStorage`
2. 页面初始化（`enhanceCollapsibleToc` 运行时）应读取 `localStorage`：
   - 若某条目在存储中标记为折叠，则初始化为折叠态（`li.is-collapsed` 且 `aria-expanded="false"`）
3. 存储粒度：
   - 以 TOC 条目对应的**首个锚点 href**（例如 `#a`）作为标识。
   - 若没有可用 href，则退化为该条目的索引标识（保证不会报错）。

## 验收标准
- 在同一页面：点击折叠按钮会更新 `localStorage`，再次调用 `enhanceCollapsibleToc`（模拟页面重进）能恢复折叠态。
- 不破坏现有能力：
  - 只有含子列表的 `li` 才有折叠按钮
  - 仍然保持幂等（重复调用不重复插入按钮）

## 边界 / 不做
- 不做“每篇文章单独记忆”的复杂逻辑（本次为全站统一记忆）。
- 不做过期清理策略（存储量很小，仅保存折叠的条目）。
- `localStorage` 不可用（隐私模式/禁用）时应静默降级，不影响功能。
