# Spec: 站内搜索支持 `#标签` 精准按标签搜索

- Date: 2026-03-09 00:37 (Asia/Shanghai)
- Slug: search-tag-query

## 背景 / 问题
当前站内搜索会在“标题 + 标签”里做混合匹配。当用户明确想“只按标签找文章”时（例如想看所有 `AI` / `Trading` 相关），只能输入关键词后依赖排序；有时会被标题命中干扰。

## 需求
为站内搜索增加一个**用户可感知**的小功能：
- 当搜索框输入以 `#` 开头的查询（例如 `#AI`、`#trading`、`#AI agent`）时，进入“标签搜索模式”：
  - **只在 tags 中匹配**（忽略 title/正文摘要）
  - 结果里的标签高亮照常生效
- 普通查询（不以 `#` 开头）保持现有行为不变。

## 验收标准
1. `#foo` 查询：
   - 若某文章 tags 包含 `foo`（大小写不敏感，包含匹配即可），则该文章会出现在结果中。
   - 若仅 title 包含 `foo`、但 tags 不包含，则不应出现。
2. `foo`（不带 `#`）查询：现有 title/tags 混合匹配不受影响。
3. 对空输入、仅 `#`、仅空格等边界情况：不报错，返回空结果。
4. Node 测试覆盖上述行为（先失败后通过）。

## 边界 / 不做
- 不实现复杂语法（如 `#tag1 #tag2` 的 AND/OR 规则），仅按现有关键字切分（空格分词）逐个匹配。
- 不引入新依赖。
- 不更改 UI 结构，仅在 JS 逻辑层实现。

## 影响范围
- `themes/evan/source/js/site-search.js`
- `tests/` 新增单元测试
