# Spec: 站内搜索弹窗内 Esc 优先清空输入

- 时间：2026-03-11 01:53 (Asia/Shanghai)
- 目标：降低搜索操作摩擦：当用户在搜索框里输入了一串内容，按 Esc 应先清空输入（保持弹窗打开），再按一次 Esc 才关闭。

## 用户故事

作为使用站内搜索的读者：
- 我输入了一段关键词但想换个关键词时，希望按一下 `Esc` 就能快速清空输入重新搜；
- 当输入框已为空时，按 `Esc` 才关闭弹窗。

## 需求

### R1. Esc 行为优先级
- 条件：弹窗处于打开状态（`is-open`）。
- 若弹窗内搜索输入框当前 `value` 非空：
  - 按 Esc：清空输入框 `value`，并触发一次 `input` 事件以刷新为“空查询”状态（显示热门标签/最近记录等），弹窗保持打开。
- 若输入框 `value` 为空：
  - 按 Esc：关闭弹窗（保持现有行为）。

### R2. 不影响页面其它 Esc
- 仅在站内搜索弹窗打开时接管该逻辑。

## 验收标准
- 新增 JSDOM 集成测试：
  - 打开弹窗，输入框填入内容后按 Esc：弹窗仍打开且输入框清空。
  - 再按一次 Esc：弹窗关闭。
- `npm test` 全绿。

## 边界/不做
- 不修改其它快捷键。
- 不新增 UI。
