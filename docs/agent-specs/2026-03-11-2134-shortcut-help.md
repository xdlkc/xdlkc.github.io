# Spec: 快捷键帮助面板（Shortcut Help Overlay）

- 时间：2026-03-11 21:34 (Asia/Shanghai)
- 功能名：快捷键帮助面板

## 背景 / 用户价值
站点已经提供了不少快捷键（如目录切换、阅读进度条折叠、站内搜索快捷键等），但用户不容易发现与记住。

新增一个“快捷键帮助面板”，用户按 `?`（Shift + /）或点击导航按钮即可打开，快速查看可用快捷键。

## 需求
1) 页面提供一个可点击入口：导航栏增加一个按钮（可用 `?` 作为可见文本），用于打开帮助面板。
2) 键盘入口：在非输入状态下，按 `?` 打开帮助面板。
3) 关闭方式：
   - 按 `Esc` 关闭
   - 点击遮罩层关闭
4) 面板内容：列出至少以下快捷键（文案随语言模式切换，zh/en）：
   - `?`：打开/关闭快捷键帮助
   - `/`：打开站内搜索（如果站内搜索存在）
   - `t`：切换目录（TOC）显示（若目录存在则有效）
   - `p`：折叠/展开阅读进度条
   - `Esc`：关闭弹窗
5) 可访问性：
   - 使用 `role="dialog"` + `aria-modal="true"`
   - 打开时将焦点移入面板，关闭时尽量恢复到触发元素

## 验收标准
- 站点模板中包含按钮与脚本引用（构建后页面可直接使用）。
- `node --test` 全部通过，新增测试覆盖：
  - 按 `?` 能打开面板
  - 按 `Esc` 能关闭面板
  - 在 input/textarea 聚焦时按 `?` 不应打开

## 边界 / 非目标
- 不做完整“动态探测当前页面哪些快捷键可用”的复杂逻辑；面板以固定清单为主。
- 不引入外部依赖。
- 不改动既有快捷键行为（只做帮助展示）。
