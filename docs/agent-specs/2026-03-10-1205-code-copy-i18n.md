# Spec: 代码块复制按钮/提示支持中英双语（随语言切换即时更新）

- 时间：2026-03-10 12:05 (Asia/Shanghai)
- Feature 名称：Code Copy i18n

## 需求
当前代码块复制功能（按钮文案、aria-label、toast 提示）为中文硬编码：
- 英文模式（`html[data-lang-mode="en"]`）下仍显示“复制代码/复制成功/已复制 X 行”，体验割裂。

需要让复制按钮与提示随站点语言模式（en/zh）展示对应文案，并在用户切换语言时即时更新。

## 验收标准
1. 当 `document.documentElement.dataset.langMode === 'en'`：
   - 按钮初始文案为 `Copy code`
   - aria-label 为 `Copy code`
   - 复制成功 toast 文案形如 `Copied 3 lines`
   - 按钮成功反馈文案形如 `Copied (3 lines)`
   - 失败 toast 文案为 `Copy failed, please copy manually`

2. 当 `langMode === 'zh'`：保持当前中文体验不变（兼容）。

3. 语言切换时（触发 `window` 的 `xdlkc:lang-change` 事件）：
   - 已注入的 `.code-copy-button` 文案与 aria-label 会切换到新语言（不需要重新 init）

## 边界
- 不修改复制逻辑本身（clipboard/fallback 等）
- 不引入新依赖

## 测试（TDD）
- 新增 tests：
  - en 模式下按钮与 toast 为英文
  - `xdlkc:lang-change` 事件能更新按钮文本

## 实现方案（最小改动）
- `themes/evan/source/js/code-copy.js`
  - 提供 `resolveLang()` + `i18nText()`
  - 将硬编码中文文案替换为根据 langMode 的文案
  - 在 `initCodeCopy` 内监听 `xdlkc:lang-change` 并更新现存按钮
