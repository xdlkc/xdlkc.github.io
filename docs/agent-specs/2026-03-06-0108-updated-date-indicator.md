# Spec: 文章页显示“最后更新”日期

## 背景
当前文章页仅展示发布日期。对持续迭代的技术文章，读者无法判断内容是否近期维护，影响信任感与阅读决策。

## 需求
在文章详情页标题下的元信息中，按条件显示“更新于 YYYY-MM-DD”。

## 验收标准
1. 当文章存在 `updated` 时间，且与 `date` 不是同一天时，元信息显示：`发布于 YYYY-MM-DD · 更新于 YYYY-MM-DD · 预计阅读 X 分钟`。
2. 当 `updated` 缺失，或与 `date` 同一天时，不显示“更新于”。
3. 日期格式统一为 `YYYY-MM-DD`。
4. 仅影响文章详情页（post）元信息，不改动首页与归档页。
5. 不引入新依赖，不影响现有阅读时长与 canonical 功能。

## 边界与非目标
- 不展示精确时间（时分秒）。
- 不处理“更新时间早于发布时间”的数据修正，仅按日期是否同一天判断展示。
- 不新增前端交互，仅做静态信息增强。
