# Spec: 键盘可访问性 Skip Link（跳转到主内容）

## 背景
当前页面顶部导航较长，键盘用户（Tab 导航）每次进入页面都需要重复穿过导航后才能到主内容，影响可用性与无障碍体验。

## 需求
为博客主题增加一个全站可用的“跳转到主内容”链接（Skip Link）：

1. 页面加载后，键盘焦点首次进入页面时可访问该链接；
2. 激活该链接后，焦点和视图应跳转到页面主内容区域；
3. 不影响鼠标用户正常视觉体验（默认可隐藏，仅聚焦时显示）。

## 验收标准
1. `themes/evan/layout/layout.ejs` 包含指向 `#main-content` 的 skip link；
2. 首页、文章页、独立页面模板都存在且仅存在一个主内容容器，带 `id="main-content"`；
3. 样式文件包含 `.skip-link` 的默认隐藏与 `:focus` 可见规则；
4. 自动化测试覆盖上述结构要求并通过。

## 边界与非目标
- 不改动信息架构与导航内容；
- 不引入新的 JS 逻辑；
- 不做多语言文案切换，先使用中文固定文案“跳转到正文”。
