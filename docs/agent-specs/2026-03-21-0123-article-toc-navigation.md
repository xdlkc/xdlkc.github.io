# Spec: 文章页自动 TOC（目录）与锚点导航

## 需求 (Requirement)
在博客文章页面自动生成一个可点击的目录 (TOC)，并为文章中的标题 (H2, H3, H4) 生成锚点，实现平滑滚动导航。

## 验收标准 (Acceptance Criteria)
1.  文章页面加载后，侧边栏或固定位置显示文章目录。
2.  目录项应与文章中的 H2, H3, H4 标题对应。
3.  点击目录项，页面平滑滚动到对应的标题位置。
4.  目录应能正确识别并链接到文章中的所有 H2, H3, H4 标题。
5.  当用户滚动页面时，目录中的当前活跃项应高亮显示。

## 边界 (Boundaries)
1.  只处理 Markdown 渲染后的 HTML 结构中的 H2, H3, H4 标签。
2.  不考虑多级嵌套标题 (例如，H2 下面直接是 H4)。
3.  TOC 的样式应与现有博客主题风格保持一致或接近。
4.  移动端适配：目录应在小屏幕上自动隐藏或折叠，并提供按钮展开。
