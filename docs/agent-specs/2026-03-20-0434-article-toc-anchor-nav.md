# 功能名称：文章页自动 TOC（目录）与锚点导航

## 需求
在博客文章页面，根据文章中的 H2, H3 标题自动生成一个可点击的目录 (Table of Contents)。目录项应包含锚点链接，点击后可平滑滚动到对应的文章标题位置。当用户滚动页面时，目录中的当前可视标题对应的项应高亮显示。

## 验收标准

1.  **自动生成目录:**
    *   在每篇文章页面的侧边栏或适当位置，自动生成一个基于文章内 `<h2>` 和 `<h3>` 标签的目录。
    *   目录层级应正确反映标题层级（例如，H2 为一级，H3 为二级）。
    *   目录中的每个条目都应该是可点击的链接。
2.  **锚点导航:**
    *   点击目录中的任意链接，页面应平滑滚动到对应的标题位置。
    *   每个 `<h2>` 和 `<h3>` 标签应自动生成一个唯一的 ID 作为锚点。
3.  **当前标题高亮:**
    *   当用户滚动页面时，目录中当前在视口内的标题对应的目录项应处于高亮状态，清晰指示用户当前阅读位置。
4.  **兼容性:**
    *   支持主流现代浏览器（Chrome, Firefox, Safari, Edge）。
    *   在移动设备上，目录可以折叠或隐藏，或以其他适应方式展现。
5.  **性能:**
    *   目录生成和高亮逻辑不应引入明显的性能开销，确保页面加载和滚动流畅。

## 边界与约束

*   只处理 `<h2>` 和 `<h3>` 标签。更高或更低的标题层级不生成目录项。
*   目录的样式和位置将根据现有博客主题进行调整，以保持一致性。
*   如果文章没有 H2 或 H3 标题，则不显示目录。
*   平滑滚动是可选的用户体验增强，如果实现复杂，可退回即时跳转。
*   高亮逻辑需考虑标题部分或全部进入视口的情况。

## 技术实现初步设想

*   **TOC 生成:** 在文章渲染阶段（前端或构建时），解析 Markdown/HTML 内容，提取 H2/H3 标题，并为其添加 `id` 属性。
*   **锚点链接:** 使用 JavaScript 监听目录点击事件，阻止默认跳转，并使用 `window.scrollTo` 或 `element.scrollIntoView` 实现平滑滚动。
*   **高亮逻辑:** 使用 Intersection Observer API 监听标题元素进入/离开视口，根据回调结果更新目录项的 CSS 类。
