# Spec: 热门标签云（Hot Tags Cloud）

- Date: 2026-03-18 04:35 (Asia/Shanghai)
- Slug: hot-tags-cloud

## 背景 / 问题
当前博客的标签功能仅在文章页面显示标签列表，首页和归档页面没有聚合的标签展示。用户无法快速查看博客的热门标签或通过标签筛选感兴趣的文章。

用户期望有一个标签云组件，能够：
- 直观展示博客的热门标签
- 通过字体大小反映标签的热度（文章数量）
- 点击标签快速跳转到标签页查看相关文章

## 需求
为博客添加热门标签云组件：

### R1. 热门标签云组件
- 在侧边栏或首页添加热门标签云组件
- 显示博客中文章数量最多的前 10-15 个标签
- 标签字体大小根据文章数量分级（最少文章的标签最小，最多的最大）
- 标签之间有适当的间距
- 支持点击标签跳转到标签页（`/tags/<tag-name>`）

### R2. 视觉设计
- 使用 CSS `font-size` 属性控制标签字体大小
- 最小字体大小：12px（或 0.8rem）
- 最大字体大小：20px（或 1.5rem）
- 使用渐变色或不同颜色区分标签热度（可选）
- 标签悬停时有明显的视觉反馈（颜色变化、下划线等）

### R3. 响应式设计
- 移动端标签云自适应布局（网格或 flex 布局）
- 避免标签在小屏幕上过于拥挤

### R4. 可配置性
- 支持配置显示的标签数量（默认 15）
- 支持配置字体大小范围

## 验收标准
1. 热门标签云组件正确显示在侧边栏或首页
2. 标签按照文章数量排序（文章多的在前面）
3. 标签字体大小根据文章数量分级
4. 点击标签可以跳转到对应的标签页
5. 移动端标签云布局正常
6. 新增测试文件 `tests/hot-tags-cloud.test.js`
7. `npm test` 全部通过

## 边界 / 不做
- 不实现标签管理功能（添加、删除、重命名标签）
- 不实现标签统计功能（文章数量统计由 Hexo 提供）
- 不实现标签搜索功能
- 不实现标签的增删改查
- 不修改标签页面的现有布局

## 技术细节

### 文件变更
- `themes/evan/layout/_partial/hot-tags-cloud.ejs` - 新增热门标签云组件模板
- `themes/evan/layout/sidebar.ejs` - 在侧边栏引入热门标签云组件（如果存在）
- `themes/evan/source/css/_partial/hot-tags-cloud.styl` - 新增热门标签云样式（可选）
- `tests/hot-tags-cloud.test.js` - 新增热门标签云测试

### 数据源
Hexo 提供的 `site.tags` 对象，包含所有标签及其文章数量：
```javascript
site.tags.each(tag => {
  tag.name      // 标签名称
  tag.posts.length  // 标签下的文章数量
})
```

### 实现逻辑
1. 遍历 `site.tags`，获取所有标签及其文章数量
2. 按文章数量降序排序
3. 取前 N 个标签（N 可配置，默认 15）
4. 根据文章数量计算标签字体大小（线性插值）
5. 渲染标签云 HTML

### 风险
- 低风险：只添加新组件，不影响现有功能
- 如果标签数量很少，需要处理边界情况

### 示例代码
```ejs
<div class="hot-tags-cloud">
  <h3><%= __('Hot Tags') %></h3>
  <div class="tags-cloud">
    <% site.tags.sort('posts.length', -1).limit(15).each(tag => { %>
      <% const size = calculateTagSize(tag.posts.length, minSize, maxSize) %>
      <a href="<%- url_for(tag.path) %>" class="tag-cloud-item" style="font-size: <%= size %>px;">
        <%= tag.name %>
      </a>
    <% }) %>
  </div>
</div>
```
