# Spec: Auto TOC for Article Pages

## Objective
Automatically generate a Table of Contents (TOC) with anchor links on blog post pages to improve navigation.

## Requirements
- Render TOC inside `<aside class="post-toc">` only if `page.toc` is true or if content has headings.
- Clickable anchor links to jump to headings.
