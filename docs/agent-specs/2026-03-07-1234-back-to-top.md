# Spec: Back to Top 浮动按钮（返回顶部）

- 时间：2026-03-07 12:34 (Asia/Shanghai)
- Slug: back-to-top

## 背景 / 用户价值
长文章阅读到中后段时，返回页面顶部需要长距离滚动。新增一个“返回顶部”浮动按钮，提升浏览效率。

## 需求
1. 在全站页面（使用主题 layout.ejs 的页面）右下角提供一个“返回顶部”浮动按钮。
2. 默认隐藏；当页面向下滚动超过阈值（默认 420px）后显示。
3. 点击按钮后平滑滚动到顶部（`scrollTo({ top: 0, behavior: 'smooth' })`）；如果浏览器不支持则降级为 `scrollTo(0, 0)`。
4. 可访问性：
   - `button[type=button]`
   - `aria-label="返回顶部"`
   - 支持键盘触发（button 默认即可）
5. 不影响现有布局与交互（不遮挡阅读进度条/搜索/主题切换等）。

## 验收标准
- 向下滚动超过 420px 后按钮可见；回到阈值之上按钮再次隐藏。
- 点击按钮后页面滚动位置回到顶部（或触发对 `window.scrollTo` 的调用）。
- Node 测试覆盖：显示逻辑 + 初始化插入按钮 + 点击触发滚动。

## 边界 / 不做
- 不做“显示当前滚动百分比”的增强（已有阅读进度条）。
- 不做在移动端根据软键盘/地址栏变化的额外适配。
- 不做在特定页面禁用（保持一致）。
