# Spec: 归档页面的年份折叠/展开（Archive Year Collapsible）

- Date: 2026-03-17 18:20 (Asia/Shanghai)
- Slug: archive-year-collapsible

## 背景 / 问题
当前归档页面显示所有文章，按年份分组，但年份列表可能很长，需要滚动很多才能找到特定年份的内容。

用户期望：
- 可以折叠不感兴趣的年份，减少页面滚动
- 保持默认展开（避免影响首次访问体验）
- 状态可以持久化（下次访问时记住折叠状态）

## 需求
为归档页面的年份分组添加折叠/展开功能：

### R1. 折叠按钮位置和样式
- 每个年份分组标题前添加折叠/展开按钮（+/- 或箭头图标）
- 按钮位于年份标题左侧，对齐美观
- 按钮悬停时有 hover 效果
- 在移动端和桌面端都可用

### R2. 折叠/展开交互
- 点击按钮时，切换该年份下文章列表的显示/隐藏
- 按钮图标随状态变化（展开时显示收起图标，折叠时显示展开图标）
- 使用 CSS transition 实现平滑的折叠/展开动画（可选）

### R3. 默认状态
- 所有年份默认展开（保持现有用户体验）
- 如果有折叠状态，优先使用本地存储的状态

### R4. 状态持久化
- 使用 localStorage 存储每个年份的折叠状态
- 存储键名：`xdlkc:archive:collapsed`（JSON 数组，存储折叠的年份）
- 下次访问时自动恢复之前的折叠状态

### R5. 无障碍性
- 折叠按钮有 `aria-expanded` 属性（true/false）
- 年份分组使用 `role="group"` 或语义化元素
- 键盘可访问（Tab 键可聚焦，Enter/Space 可触发）
- 折叠状态的变更通过 ARIA 属性通知屏幕阅读器

### R6. 性能和兼容性
- 使用纯 JavaScript 和 CSS，不依赖外部库
- 不影响页面加载性能
- 支持所有现代浏览器

## 验收标准
1. 每个年份分组都有折叠/展开按钮
2. 点击按钮可以切换文章列表的显示/隐藏
3. 按钮图标随状态正确变化
4. 折叠状态可以持久化到 localStorage
5. 刷新页面后可以恢复之前的折叠状态
6. 移动端和桌面端都能正常使用
7. 键盘导航可以访问折叠按钮
8. 新增测试文件 `tests/archive-year-collapsible.test.js`
9. 新增 JS 文件 `js/archive-year-collapsible.js`
10. `layout.ejs` 或 `archive.ejs` 引入 `archive-year-collapsible.js`
11. `npm test` 全部通过

## 边界 / 不做
- 不实现"全部折叠/全部展开"按钮（可以后续添加）
- 不支持自定义动画效果
- 不支持年份排序（保持现有排序）
- 不修改归档页面的其他样式和功能
