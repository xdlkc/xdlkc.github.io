# Spec: 文章代码块复制按钮与复制成功提示

- 时间：2026-03-06 12:28 (Asia/Shanghai)
- 状态：Draft -> Implemented in this run

## 背景
文章页面存在较多代码块，读者复制代码需要手动选中，操作繁琐且容易漏选。需要提供“一键复制 + 明确反馈”。

## 需求
1. 在文章页每个代码块（`article-content` 内的 `pre`）右上角展示“复制代码”按钮。
2. 点击后复制该代码块纯文本内容到剪贴板。
3. 复制成功后给出用户可见反馈（提示文案），并在短时间后自动消失/恢复。
4. 不影响现有 Mermaid 渲染逻辑与普通阅读布局。

## 验收标准
- [ ] 文章模板包含代码复制增强脚本，覆盖 `article-content pre`。
- [ ] 脚本创建 `code-copy-button` 按钮并绑定点击事件。
- [ ] 脚本优先使用 `navigator.clipboard.writeText`，并提供兼容 fallback。
- [ ] 成功反馈通过 `code-copy-toast` 显示“复制成功”。
- [ ] 样式文件提供 `code-copy-button` 与 `code-copy-toast` 可见样式。

## 边界与非目标
- 本轮不做“复制失败原因细分提示”，失败仅给统一文案。
- 本轮不覆盖文章正文之外的代码块（如首页摘要场景）。
- 本轮不引入第三方库。
