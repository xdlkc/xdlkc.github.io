# Site Search Query Summary

## Requirement

在站内搜索弹层中，为当前查询增加“结果摘要”展示，让用户一眼看懂当前到底在搜什么、命中了多少条。

## User value

- 普通关键词搜索时，结果区顶部明确显示当前查询与结果数。
- 标签搜索（如 `#AI` / `tag:AI`）时，明确显示这是“标签搜索”，减少歧义。
- 分类搜索（如 `cat:notes`）时，明确显示这是“分类搜索”。
- 无结果时也保留查询摘要，帮助用户理解为什么没搜到，并配合现有建议继续调整。

## Acceptance criteria

1. 有结果时，结果区顶部渲染一个查询摘要区域，至少包含：
   - 当前查询值
   - 查询类型（关键词 / 标签 / 分类）
   - 结果数量
2. 无结果时，空状态顶部也渲染同样的查询摘要区域。
3. `#AI` 与 `tag:AI` 都应显示为“标签：AI”。
4. `cat:notes` / `category:notes` 应显示为“分类：notes”。
5. 普通关键词（如 `agent notes`）应显示为“搜索：agent notes”。
6. 保持现有高亮、推荐词、外部搜索链接等行为不变。

## Boundaries

- 本轮不改搜索排序算法。
- 本轮不新增复杂筛选器 UI，只增加摘要展示。
- 本轮不改搜索索引结构。
