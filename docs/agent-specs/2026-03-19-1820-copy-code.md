# Spec: Code Block Copy Button

## Requirement
Add a "Copy" button to all code blocks (`pre > code`) on article pages. Clicking the button copies the code to the clipboard and shows a "Copied!" notification.

## Acceptance Criteria
1. Button appears on hover or statically in the top right of code blocks.
2. Code is correctly copied without adding extra DOM elements' text.
3. Visual feedback (e.g., text changes to "Copied!" then reverts).

## Boundaries
- Only applies to standard Markdown generated code blocks.
