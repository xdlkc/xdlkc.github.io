# Spec: 暗色模式自动切换 (基于系统时间/日出日落)

## 需求 (Requirement)
博客应能根据系统时间（或模拟的日出日落时间）自动切换暗色/亮色模式，提升用户体验。用户应能通过配置开启或关闭此功能。

## 验收标准 (Acceptance Criteria)
1.  当用户开启自动切换功能时，根据预设的“白天”和“夜晚”时间段自动应用亮色或暗色模式。
2.  如果用户手动切换了主题，自动切换功能应暂时失效，直到下一次“白天/夜晚”边界切换（即用户手动选择的优先级更高，但仅限于当前时间段，下一时间段应恢复自动切换）。
3.  提供一个配置项（例如在 `_config.yml` 中）来启用或禁用此功能。
4.  测试覆盖自动切换的逻辑，包括时间段判断和主题应用。

## 边界 (Boundaries)
1.  简单起见，初始版本可使用固定的“日出”和“日落”时间（例如，8:00 AM 和 6:00 PM），而不是精确的地理位置日出日落 API。
2.  自动切换功能应在页面加载时执行一次，并在后续时间段边界检查（例如，每小时检查一次，或监听系统时间变化）。
3.  优先级别：URL参数 > 用户手动选择 (当前时段) > 自动切换 > 系统偏好。
