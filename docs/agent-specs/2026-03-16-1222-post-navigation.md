# 文章上一篇/下一篇导航

## 功能描述
在博客文章页面添加上一篇/下一篇导航链接，方便用户在文章之间快速切换。

## 需求
1. **导航位置**：在文章末尾（Related Posts 之前或之后）显示上一篇/下一篇链接
2. **导航内容**：
   - 显示上一篇文章的标题和链接（如果有）
   - 显示下一篇文章的标题和链接（如果有）
   - 使用图标或文字区分（← 上一篇，下一篇 →）
3. **响应式设计**：
   - 桌面端：上一篇和下一篇并排显示
   - 移动端：上下堆叠显示
4. **无障碍性**：
   - 使用语义化的 HTML 标签
   - 添加适当的 ARIA 属性
   - 支持键盘导航
5. **国际化**：
   - 支持"上一篇"/"下一篇"的多语言切换

## 验收标准
- [ ] 文章页面显示上一篇/下一篇导航
- [ ] 只有上一篇时只显示上一篇
- [ ] 只有下一篇时只显示下一篇
- [ ] 两者都有时都显示
- [ ] 两者都没有时不显示导航区域
- [ ] 点击链接可以正确跳转到对应文章
- [ ] 响应式布局正确
- [ ] 支持多语言（中文/英文）
- [ ] 测试通过

## 边界
- 仅在文章页面显示（post.ejs）
- 基于文章日期排序（最新的作为下一篇，最旧的作为上一篇）
- 不在首页、归档页等其他页面显示
- 不修改现有的文章排序逻辑

## 实现方式
1. 在 `themes/evan/layout/post.ejs` 中添加导航 HTML
2. 使用 Hexo 的 `page.prev` 和 `page.next` API 获取上一篇/下一篇文章
3. 在 `themes/evan/source/css/style.css` 中添加样式
4. 在 `js/lang-toggle.js` 中添加多语言支持（如果需要）

## 测试方案
1. 检查是否有上一篇文章时的显示
2. 检查是否有下一篇文章时的显示
3. 检查两者都有时的显示
4. 检查两者都没有时的显示
5. 点击链接验证跳转是否正确
6. 检查响应式布局
7. 检查多语言切换

## 备注
- Hexo 默认提供 `page.prev` 和 `page.next` 属性
- 排序基于配置文件中的 `order_by: -date` 设置
- 需要考虑没有上一篇文章（最新一篇）和没有下一篇文章（最旧一篇）的情况
