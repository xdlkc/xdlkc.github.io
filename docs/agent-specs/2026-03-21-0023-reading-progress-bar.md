# Feature Specification: 阅读进度条 (Reading Progress Bar)

## 需求 (Requirements)
在博客文章页面顶部显示一个阅读进度条，指示用户当前的阅读位置。

## 验收标准 (Acceptance Criteria)
1.  **可见性**: 仅在博客文章详情页（即 `_posts` 目录下的文章）显示进度条。
2.  **位置**: 进度条固定在页面顶部。
3.  **功能性**: 
    *   用户向下滚动页面时，进度条从左到右填充。
    *   进度条的宽度应与文章的滚动深度成比例。
    *   当文章内容完全进入视口或滚动到底部时，进度条应完全填充。
4.  **样式**: 
    *   进度条应有一个独特的颜色（例如，品牌色或对比色）。
    *   进度条的高度应适中，不应过于突兀。
    *   应平滑地更新，而不是跳跃式更新。
5.  **兼容性**: 在主流浏览器 (Chrome, Firefox, Safari) 上表现一致。

## 边界 (Boundaries)
*   **不适用页面**: 非文章页面（如首页、分类页、标签页）不显示进度条。
*   **实现方式**: 使用纯 CSS 和 JavaScript 实现，避免引入大型第三方库。
*   **响应式**: 在不同屏幕尺寸下（PC, 移动设备）均能正常工作。
*   **性能**: 对页面加载和滚动性能影响最小化。
