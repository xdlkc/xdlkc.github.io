# Feature Spec: 文章页自动 TOC（目录）与锚点导航

## 需求 (Requirement)
为博客文章页面自动生成目录（Table of Contents, TOC），并为文章内 H2 和 H3 标题创建锚点导航。TOC 应以可导航的侧边栏或浮动元素形式展示，每个 TOC 项都应链接到文章中对应的标题。

## 验收标准 (Acceptance Criteria)
1.  包含 H2/H3 标题的文章页面能够正确渲染 TOC。
2.  TOC 按照 H2/H3 标题在文章中出现的顺序显示。
3.  每个 TOC 项都是可点击的链接，点击后平滑滚动到页面上对应的标题。
4.  文章中的 H2/H3 标题应自动生成唯一的锚点 ID (例如, `#section-title`)。
5.  用户滚动文章时，TOC 中当前可见的标题对应的项应高亮显示。
6.  没有 H2/H3 标题的页面不应显示 TOC。

## 边界 (Boundaries)
*   TOC 只包含 H2 和 H3 标题。
*   TOC 的样式和确切位置（侧边栏或浮动）将在实现过程中确定，优先选择简洁、不侵入的设计。
*   不为 H4 及更深层级的标题生成嵌套 TOC。
*   TOC 的生成将优先考虑客户端 JavaScript 实现，以简化静态站点生成器的集成复杂性。
