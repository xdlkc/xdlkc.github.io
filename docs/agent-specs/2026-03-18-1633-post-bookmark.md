# 文章收藏功能 (Post Bookmark)

## 需求

为文章页面添加收藏功能，允许用户标记喜欢的文章，并保存到 localStorage，以便快速访问收藏的文章列表。

## 背景

用户在浏览博客时，可能看到感兴趣的文章但暂时无法阅读完整内容，或者想要保存文章以便稍后再次查看。添加收藏功能可以让用户方便地标记和访问这些文章。

## 验收标准

1. 文章页面顶部有一个收藏按钮（🔖 / ❤️ 图标）
2. 点击按钮可以切换收藏/取消收藏状态
3. 收藏状态持久化到 localStorage
4. 收藏按钮显示当前收藏数
5. 提供收藏文章列表页面，显示所有收藏的文章
6. 收藏列表可以通过导航栏访问
7. 支持从收藏列表中取消收藏
8. 中英文双语支持

## 边界条件

- 收藏数据存储在 `xdlkc:bookmarks` localStorage 键中
- 收藏数据结构：`[{ path: string, title: string, savedAt: timestamp }]`
- 最多保存 100 篇收藏文章
- 收藏列表按保存时间倒序排列
- 不登录用户也可以收藏（本地存储）

## 实现方案

1. 创建 `themes/evan/source/js/post-bookmark.js` 模块
2. 在 `themes/evan/layout/post.ejs` 中添加收藏按钮和脚本引用
3. 在 `themes/evan/layout/_partial/bookmark-list.ejs` 中创建收藏列表页面
4. 在 `themes/evan/layout/index.ejs` 和 `post.ejs` 导航栏添加"收藏"链接
5. 使用 CSS 实现收藏按钮的视觉反馈（收藏状态高亮）

## 测试用例

1. 点击收藏按钮，状态从未收藏变为已收藏
2. 刷新页面后，收藏状态保持
3. 收藏数据正确保存到 localStorage
4. 取消收藏后，文章从收藏列表中移除
5. 收藏列表页面正确显示所有收藏的文章
6. 收藏列表按保存时间倒序排列
7. 收藏列表中可以取消收藏
8. 收藏数量超过 100 篇时，自动删除最早的文章
