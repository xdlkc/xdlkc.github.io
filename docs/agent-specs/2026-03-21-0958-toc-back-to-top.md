# 功能迭代：文章页 TOC 添加“回到顶部”链接

## 需求

在文章页面的自动生成目录（TOC）的顶部，新增一个“回到顶部”链接。用户点击此链接时，页面应平滑滚动到文章内容的起始位置，以便用户快速回到文章开头。

## 验收标准

1.  **链接存在:**
    *   在文章页面的桌面端和移动端 TOC 容器内，最顶部应显示一个标题为“回到顶部”或类似文字的链接。
    *   该链接应具有可点击性。

2.  **平滑滚动:**
    *   点击“回到顶部”链接后，页面应以平滑动画滚动到文章内容区域的顶部（即 `main-content` 元素的顶部或更上方）。
    *   滚动结束后，页面的滚动位置应确保文章的起始内容清晰可见，不会被固定头部遮挡。

3.  **用户感知:**
    *   链接文本应清晰明了（例如：“回到顶部”）。
    *   滚动效果应平滑，提升用户体验。

## 边界

*   **实现位置:** 主要修改 `toc-scrollspy.js` 来注入此链接并处理点击事件。
*   **CSS 样式:** 仅关注 JavaScript 逻辑实现。链接的样式由现有 CSS 或新增少量 CSS 定义，不在此次迭代范围内。
*   **多 TOC 实例:** 兼容桌面端和移动端 TOC 实例。
*   **语言支持:** 链接文本需要支持国际化（中文/英文）。
*   **无 TOC 情况:** 如果文章没有生成 TOC，则不应显示此链接。
