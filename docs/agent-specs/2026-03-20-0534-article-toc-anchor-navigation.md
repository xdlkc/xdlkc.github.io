# Feature Specification: 文章页自动 TOC (目录) 与锚点导航

## 需求 (Requirement)
在博客的文章详情页，自动生成一个侧边目录 (Table of Contents, TOC)，该目录应包含文章内所有 H2, H3 标题。点击目录项时，页面应平滑滚动到对应的标题位置。标题旁应显示锚点链接图标，方便用户复制直接链接。

## 验收标准 (Acceptance Criteria)
1.  **自动生成 TOC:**
    *   文章详情页侧边栏（或合适位置）显示一个目录。
    *   目录内容应包含文章主体内的所有 `<h2>` 和 `<h3>` 标签的文本。
    *   目录项应正确嵌套，反映 H2/H3 的层级关系（例如，H3 应在 H2 下方缩进）。
    *   目录项文本应与对应标题文本一致。
2.  **锚点导航:**
    *   每个目录项都是可点击的链接。
    *   点击目录项时，页面应平滑滚动到对应的 `<h2>` 或 `<h3>` 标题。
    *   滚动结束后，对应的标题应该在可视区域内，并且可以有轻微偏移以避免被固定导航栏遮挡（如果存在）。
3.  **锚点链接图标:**
    *   每个 `<h2>` 和 `<h3>` 标题旁边（或合适位置）应显示一个可点击的锚点图标（例如 `#` 或链条图标）。
    *   点击锚点图标时，应将当前页面的该标题的锚点 URL 复制到剪贴板，或者直接更新浏览器URL哈希。
    *   标题的 `id` 属性应根据其文本内容自动生成，并确保唯一性，例如将中文或特殊字符转换为英文拼音或 slug。
4.  **激活状态:**
    *   当用户滚动页面时，TOC 中当前在视口内的标题对应的目录项应高亮显示。
5.  **无标题情况:**
    *   如果文章中没有 H2 或 H3 标题，则不显示 TOC。

## 边界 (Boundaries)
*   **支持的标题级别:** 仅限 `<h2>` 和 `<h3>`。
*   **平滑滚动:** 使用 CSS `scroll-behavior: smooth;` 或 JavaScript 实现平滑滚动。
*   **样式:** TOC 和锚点图标的初始样式应简洁，不破坏现有页面布局，后续可优化。
*   **性能:** TOC 生成应在客户端高效完成，不影响页面加载速度。
*   **兼容性:** 考虑主流浏览器（Chrome, Firefox, Safari, Edge）的兼容性。
*   **Markdown/HTML 解析:** 确保能正确解析 Markdown 渲染后的 HTML 结构来提取标题。
*   **URL 兼容性:** 确保生成的锚点 ID 对于 URL 是安全的。

## 技术选型建议
*   **TOC 生成:** 可以考虑在 Markdown 渲染时（服务端）或在客户端 JavaScript 中动态生成。
*   **唯一 ID 生成:** 为标题生成唯一 ID，可以使用现有的库或者简单的前缀加索引方式。
*   **滚动监听:** 使用 `Intersection Observer API` 或 `scroll` 事件来监听标题进入视口的情况。
