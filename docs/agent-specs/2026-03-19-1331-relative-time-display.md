# 文章相对时间显示

## 需求

在文章页面的元数据区域显示相对时间（如"3天前"、"2小时前"、"5分钟前"），让用户更直观地了解文章的新旧程度。

## 验收标准

1. 在文章页面的元数据区域显示相对时间
2. 支持多种时间单位：
   - 分钟：1-59 分钟前
   - 小时：1-23 小时前
   - 天：1-30 天前
   - 月：1-12 个月前
   - 年：1年以上（显示具体年数，如"2年前"）
3. 支持中英文双语：
   - 中文："3天前"、"2小时前"、"5分钟前"
   - 英文："3 days ago"、"2 hours ago"、"5 minutes ago"
4. 相对时间显示在发布时间旁边，用括号包裹，如：
   - "Published 2026-03-19 (2 days ago)"
   - "发布于 2026-03-19（2天前）"
5. 对于文章更新时间，也显示相对时间，如：
   - "Published 2026-03-19 (2 days ago) · Updated 2026-03-18 (3 days ago)"
   - "发布于 2026-03-19（2天前）· 更新于 2026-03-18（3天前）"

## 边界

1. 相对时间计算基于当前时间
2. 如果文章发布时间小于 1 分钟，显示"刚刚"或"just now"
3. 如果文章发布时间大于 365 天，显示具体年数，如"2年前"或"2 years ago"
4. 如果文章没有更新时间，只显示发布时间的相对时间
5. 在归档页、首页等其他页面不显示相对时间（保持原有显示）

## 实现方案

1. 创建 Hexo helper 函数 `relative_time(date)` 用于计算相对时间
2. 创建 Hexo helper 函数 `relative_time_with_label(date, type)` 用于生成带标签的相对时间字符串
3. 在文章页面模板中使用这些函数显示相对时间
4. 支持通过 `document.documentElement.dataset.langMode` 判断当前语言
5. 使用 JavaScript 在前端动态计算相对时间（更准确）

## 测试要点

1. 测试不同时间范围的相对时间显示
   - 30秒前：刚刚 / just now
   - 5分钟前：5分钟前 / 5 minutes ago
   - 2小时前：2小时前 / 2 hours ago
   - 3天前：3天前 / 3 days ago
   - 2个月前：2个月前 / 2 months ago
   - 2年前：2年前 / 2 years ago
2. 测试中英文双语切换
3. 测试文章发布时间和更新时间的相对时间都正确显示
4. 测试边界情况（无更新时间、小于1分钟等）
