# Spec: 文章引用快速复制

- Date: 2026-03-19 01:02 (Asia/Shanghai)
- Feature slug: quote-copy

## 背景 / 问题
用户阅读文章时可能想引用其中的某些内容分享到社交媒体或笔记中。目前需要手动选中、复制、打开应用、粘贴、添加来源信息，流程繁琐。

用户期望有更方便的方式：选中文字后，一键复制格式化的引用（自动包含文章标题和链接）。

## 需求
为博客文章添加引用快速复制功能：

### R1. 选中文本检测
- 监听用户的文本选择事件（`selectionchange`）
- 只在文章内容区域内（`.article-content`）响应选择
- 当选择长度 >= 5 个字符时，显示引用复制按钮

### R2. 引用复制按钮
- 按钮以工具提示（tooltip）形式出现在选中文本附近
- 按钮文本：中英文切换（"引用"/"Quote"）
- 点击按钮复制格式化引用到剪贴板
- 复制后显示成功提示（toast）

### R3. 引用格式
引用格式为：
```
> [选中的文本]

— [文章标题](文章链接)
```

示例：
```
> Hexo 是一个快速、简洁且高效的博客框架。

— Hexo 入门指南(https://example.com/posts/hexo-tutorial/)
```

### R4. 用户体验
- 按钮位置智能计算，避免遮挡选中文本
- 点击页面其他区域或选择改变时自动隐藏按钮
- 支持中英文语言切换
- 键盘用户友好（不干扰正常选择操作）

## 验收标准
1. 在文章内容区域选中 5+ 个字符后，引用复制按钮出现
2. 点击按钮成功复制格式化引用到剪贴板
3. 复制后显示成功提示（toast）
4. 按钮位置不遮挡选中文本
5. 取消选择或点击其他区域时按钮自动隐藏
6. 支持中英文语言切换
7. 新增测试文件 `tests/quote-copy.test.js`
8. `npm test` 全部通过

## 边界 / 不做
- 不修改原生复制/粘贴行为
- 不支持富文本复制（只复制纯文本格式）
- 不支持跨文章引用复制
- 不修改文章页面的其他选择行为

## 技术细节

### 文件变更
- `themes/evan/source/js/quote-copy.js` - 新增引用复制功能脚本
- `themes/evan/layout/post.ejs` - 引入脚本 `<script src="<%- url_for('/js/quote-copy.js') %>" defer></script>`
- `themes/evan/source/css/_partial/quote-copy.styl` - 新增样式（可选，可内联到主样式）

### 实现逻辑
1. 监听 `selectionchange` 事件（或 `mouseup`/`keyup` 事件）
2. 检测选区是否在 `.article-content` 内
3. 如果选中文本长度 >= 5，显示工具按钮
4. 按钮位置：根据选区坐标计算最佳位置
5. 点击按钮时：
   - 获取选中文本、文章标题、文章URL
   - 组合格式化引用字符串
   - 复制到剪贴板（优先使用 Clipboard API）
   - 显示成功提示 toast
6. 选区改变或清空时隐藏按钮

### 风险
- 低风险：只添加新功能，不影响现有选择行为
- 移动端选区计算可能需要额外处理

### 示例代码
```javascript
function formatQuote({ text, title, url }) {
  return `> ${text}\n\n— [${title}](${url})`;
}
```
