# Spec: 站内搜索支持 Enter 直接打开第一条结果

- 时间：2026-03-07 06:34 (Asia/Shanghai)
- Slug: site-search-enter-open-first

## 背景 / 用户价值
当前站内搜索弹窗需要鼠标点击结果才能跳转。对键盘党来说，输入关键词后按 Enter 直接打开最匹配的第一条结果，会明显更快、更「可感知」。

## 需求
在站内搜索弹窗（`themes/evan/source/js/site-search.js`）中：

1. 当搜索结果列表存在且至少 1 条时：
   - 在输入框按 **Enter**：直接打开第一条结果。
2. 当没有结果时：
   - Enter 不做跳转。
3. 边界/约束：
   - 仅在搜索弹窗处于打开状态（`.is-open`）时生效。
   - 如果正在输入法组合输入（`event.isComposing` 为 true）则不触发跳转。
   - 不破坏现有快捷键（`/`、`Cmd/Ctrl+K`、`Esc`）和点击逻辑。

## 验收标准
- 打开站内搜索，输入关键词出现结果后，按 Enter 能跳转到第一条结果。
- 没有结果时按 Enter 不跳转。
- `npm test` 通过，并包含覆盖上述行为的测试用例。

## 不在范围内
- 结果项的键盘上下选择（↑/↓）、高亮选中样式。
- Enter 在无结果时自动拆分关键词/选择建议 chip。
