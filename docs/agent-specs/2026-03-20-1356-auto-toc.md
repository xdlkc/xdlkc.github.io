# Spec: 文章页自动 TOC（目录）与锚点导航

## 需求 (Requirement)
在博客文章页面自动生成文章目录 (TOC) 并提供锚点导航功能。

## 验收标准 (Acceptance Criteria)
1. 文章内容中的 H1, H2, H3 标签应自动提取并生成目录。
2. 目录应显示在文章侧边栏或固定位置。
3. 点击目录项应平滑滚动到对应的标题位置。
4. 页面滚动时，目录中当前可见标题对应的项应高亮显示。
5. 当文章没有 H1, H2, H3 标签时，不显示目录。
6. TOC 的生成不应影响文章内容的渲染。
7. 所有标题（H1-H3）都应该有唯一的 ID，以便锚点跳转。

## 边界 (Boundary Conditions)
1. 仅处理文章页面 (`_posts` 或类似结构下的 Markdown 文件)。
2. 仅支持 H1, H2, H3 标签作为目录项，更深层级不包含。
3. 忽略代码块内部的标题。
