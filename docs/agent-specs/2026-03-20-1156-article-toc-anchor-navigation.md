# 功能需求：文章页自动 TOC（目录）与锚点导航

## 需求描述
在博客的文章详情页（post page），自动生成文章内容的目录（Table of Contents），并提供锚点导航功能。用户点击目录项时，页面平滑滚动到对应标题位置。

## 验收标准

1.  **自动生成目录:**
    *   文章内容中的 H2 和 H3 标题（`<h2>` 和 `<h3>`）应被自动识别并作为目录项。
    *   目录应显示在文章内容的侧边栏或顶部（具体位置待定，但优先考虑侧边栏，如果空间允许）。
    *   目录项应正确显示标题文本。
    *   H2 标题作为一级目录，H3 标题作为二级目录，有层级显示（缩进）。

2.  **锚点导航:**
    *   每个被识别的标题（H2, H3）应自动添加一个唯一的 ID 作为锚点。
    *   目录中的每个链接应指向对应的锚点 ID。
    *   点击目录链接时，页面应平滑滚动到对应的标题位置。

3.  **用户体验:**
    *   目录应在文章加载后自动生成并显示。
    *   当用户滚动页面时，当前在视口中的标题对应的目录项应有高亮显示。

4.  **兼容性:**
    *   在不同浏览器（Chrome, Firefox, Safari）上正常工作。
    *   在移动设备上，目录可能需要折叠或以其他方式优化显示。

## 边界

*   **标题层级:** 目前只考虑 H2 和 H3 标题。
*   **样式:** 初始实现关注功能，样式保持简洁，后续可优化。
*   **性能:** 目录生成不应明显影响页面加载性能。
*   **Markdown解析:** 假定文章内容已经过 Markdown 解析并生成 HTML。
