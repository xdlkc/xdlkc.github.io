# Spec: 站内搜索增强 - 文章内容搜索

- Date: 2026-03-18 05:35 (Asia/Shanghai)
- Slug: search-content-body

## 背景 / 问题

当前博客的站内搜索功能（`themes/evan/source/js/site-search.js`）支持：
- ✅ 标题搜索
- ✅ 标签搜索（`#tag` 或 `tag:xxx`）
- ✅ 分类搜索（`cat:xxx`）
- ✅ 标题/标签高亮显示
- ✅ 无结果建议

但是**缺少文章正文内容搜索**，这意味着：
- 用户无法搜索文章中的具体内容（如代码片段、技术概念、案例分析等）
- 只能通过标题、标签、分类匹配文章，匹配范围受限
- 对于"查找我之前看过的某篇文章里的内容"这类需求，用户只能手动浏览

## 需求

为站内搜索添加**文章内容搜索**能力，让用户可以搜索文章正文中的文本。

### R1. 搜索范围扩展
- 在 `scorePost` 函数中，添加对文章内容的搜索支持
- 支持搜索以下内容字段：
  - 标题（已支持）
  - 标签（已支持）
  - 分类（已支持）
  - **文章内容**（新增）
  - **文章摘要**（新增）

### R2. 评分权重策略
- 保持现有的评分权重体系：
  - 标题匹配：10分 + 额外加分
  - 标签匹配：3-6分（根据模式）
  - 分类匹配：4-8分
- 新增内容匹配权重：
  - 内容匹配：2-4分（低于标题，但高于无匹配）
  - 摘要匹配：1-2分（低于内容，作为补充）
- 这样既确保标题/标签/分类仍然优先，又让内容搜索能够生效

### R3. 搜索片段优化
- 保留现有的 `makeSnippet` 函数逻辑
- 如果查询在文章内容中匹配，片段应优先显示匹配内容部分
- 保持现有的片段高亮功能

### R4. 性能考虑
- 内容字符串较长，使用高效的字符串匹配
- 避免对每篇文章内容进行过度处理
- 保持搜索响应速度

### R5. 向后兼容
- 不改变现有的搜索语法（`#tag`, `cat:`, `tag:xxx`）
- 搜索标签/分类时，可以包含内容搜索（增强相关性）
- 普通搜索模式（无前缀）自动包含所有字段

## 验收标准

1. 用户搜索文章中的具体词汇时，能返回匹配的文章
2. 搜索结果中，匹配的词汇在搜索片段中高亮显示
3. 标题匹配仍然优先于内容匹配（标题匹配的文章排名更高）
4. 搜索性能没有明显下降（保持在120ms以内）
5. 新增测试文件 `tests/search-content-body.test.js`
6. 新增/修改 `themes/evan/source/js/site-search.js`
7. `npm test` 相关测试全部通过

## 边界 / 不做

- 不实现全文索引（使用现有 search.json 数据源）
- 不改变现有的高亮UI样式
- 不改变现有的搜索历史功能
- 不实现模糊搜索（保持现有的精确/子串匹配）
- 不实现自然语言查询解析（保持现有的简单关键词分割）
