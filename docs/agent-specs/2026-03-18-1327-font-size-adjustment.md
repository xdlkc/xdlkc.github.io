# Spec: 文章字体大小调节

- Date: 2026-03-18 13:27 (Asia/Shanghai)
- Slug: font-size-adjustment

## 背景 / 问题

不同用户的阅读偏好和视力条件差异很大：
- 有些用户偏好更大的字体以提高可读性
- 有些用户偏好较小的字体以在一屏中显示更多内容
- 移动端用户可能需要不同于桌面端的字体大小
- 默认字体大小无法满足所有用户的需求

当前博客虽然有暗色模式、阅读进度等体验优化，但**缺少字体大小调节功能**，用户无法根据个人偏好调整文章的字体大小。

## 需求

为文章页面添加字体大小调节功能，允许用户在合理的范围内调整文章内容的字体大小。

### R1. 调节范围
- 提供预设的字体大小级别：
  - 小号（Small）：14px
  - 中号（Medium，默认）：16px
  - 大号（Large）：18px
  - 超大号（Extra Large）：20px
- 用户可以通过点击按钮切换这些预设级别

### R2. 状态持久化
- 将用户的字体大小偏好保存到 localStorage
- 用户再次访问页面时，自动恢复上次选择的字体大小
- 默认值为中号（16px）

### R3. 实时生效
- 切换字体大小后，文章内容的字体立即更新
- 使用 CSS 变量实现高效的主题切换
- 不需要重新加载页面

### R4. 响应式设计
- 移动端和桌面端共享同一个字体大小设置
- 字体大小以相对于基准的百分比或 rem 为单位，确保在不同设备上表现一致

### R5. UI/UX 要求
- 在导航栏添加字体大小调节按钮
- 点击按钮时循环切换：中号 → 大号 → 超大号 → 小号 → 中号
- 显示当前字体大小级别的指示器
- 支持键盘快捷键（`f` 键）切换字体大小

### R6. 仅影响文章内容
- 字体大小调节只影响文章正文（`.article-content`）
- 不影响导航栏、侧边栏、页脚等其他区域
- 保持博客整体布局的稳定性

## 验收标准

1. 导航栏中存在字体大小调节按钮
2. 点击按钮可以切换字体大小（中号 → 大号 → 超大号 → 小号 → 中号）
3. 字体大小立即生效，不需要重新加载页面
4. 字体大小偏好正确保存到 localStorage
5. 用户再次访问页面时，自动恢复上次选择的字体大小
6. 键盘快捷键 `f` 可以切换字体大小
7. 字体大小只影响文章正文，不影响其他区域
8. 移动端和桌面端字体大小表现一致
9. 新增测试文件 `tests/font-size-adjustment.test.js`
10. 新增/修改 `themes/evan/source/js/font-size-toggle.js`
11. 新增/修改 `themes/evan/layout/post.ejs`
12. `npm test` 相关测试全部通过

## 边界 / 不做

- 不实现自定义字体大小输入（只提供预设级别）
- 不实现字体族切换（只调整大小）
- 不实现行高调整（保持默认的行高设置）
- 不实现每个段落独立的字体大小
- 不实现字体大小动画过渡（为了性能）

## 实现说明

- 使用 CSS 变量 `--article-font-size` 控制文章内容的字体大小
- 在 `.article-content` 上应用这个变量
- 使用 localStorage 的键 `xdlkc:font-size` 保存用户偏好
- 值为 `small` | `medium` | `large` | `extra-large`
- 映射关系：
  - `small` → 14px
  - `medium` → 16px
  - `large` → 18px
  - `extra-large` → 20px

## 测试策略

- 单元测试：验证字体大小级别的映射关系
- 单元测试：验证 localStorage 的读写逻辑
- 单元测试：验证 CSS 变量的设置
- 行为测试：验证点击按钮切换字体大小
- 行为测试：验证键盘快捷键切换字体大小
