# Spec: 站内搜索空状态展示「热门标签」快捷入口

- Date: 2026-03-07 23:37 (Asia/Shanghai)
- Slug: site-search-top-tags

## 背景 / 问题
当前站内搜索弹窗打开后（或输入框清空后）只显示“输入关键词开始搜索”的提示。对读者来说缺少探索入口：不知道站点常见主题，也缺少一键开始浏览的路径。

## 目标（用户可感知）
当搜索框为空时，在弹窗内展示一组“热门标签”chip；点击 chip 会自动填入该标签并触发搜索结果。

## 需求
1. 打开站内搜索弹窗时，如果已成功加载 db.json：
   - 展示「热门标签」区域（最多 10 个）
   - 同时保留原有提示文案（或更友好的引导）
2. 当输入框被清空（query 为空）时：恢复展示「热门标签」区域。
3. 点击任意热门标签 chip：
   - 将该标签写入输入框
   - 触发一次 input 事件以刷新结果
4. 热门标签计算规则：
   - 从 db.json 的 posts 中聚合 tags
   - 大小写不敏感去重（同名不同大小写视作同一个）
   - 按出现次数降序排序；次数相同按字典序升序
   - 仅保留出现次数 >= 2 的标签（避免噪声）

## 验收标准
- 空 query 时，DOM 中存在 [data-site-search-top-tags] 容器，且包含若干 [data-site-search-keyword] 按钮。
- getTopTags() 在给定 posts 数据下返回稳定、排序正确的结果。
- `npm test` 通过。

## 边界 / 非目标
- 不新增服务端能力；不改 db.json 生成逻辑。
- 不做复杂的同义词、拼写纠错等（留待后续）。
- 若 db.json 加载失败：维持现有“索引加载失败”的兜底，不强行展示热门标签。
