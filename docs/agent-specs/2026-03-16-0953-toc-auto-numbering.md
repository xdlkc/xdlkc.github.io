# Spec: 文章页 TOC 自动编号（层级锚点导航增强）

- 时间：2026-03-16 09:53 (Asia/Shanghai)
- 类型：P0 功能迭代（文章页自动 TOC 与锚点导航）

## 需求
在文章页 TOC（目录）中为每一项自动增加层级编号（如 `1`、`1.2`、`1.2.1`），帮助用户更快理解结构与定位章节。

## 用户可感知价值
- 目录层级更清晰，长文导航成本更低。
- 手机和桌面 TOC 均可直接看到章节序号。
- 不改变原有锚点跳转行为，仅增强可读性。

## 验收标准
1. TOC 链接文本前会插入一个编号节点，格式为：
   - 同级递增：`1`、`2`、`3`
   - 子级继承：`1.1`、`1.2`、`2.1`
2. 编号包含在单独元素中（例如 `.toc-index`），便于样式控制。
3. 初始化多次不会重复注入编号（幂等）。
4. 现有 TOC 功能（折叠/高亮/滚动/拷贝链接）不受影响。

## 边界与非目标
- 不改动文章正文标题文本。
- 不改动 TOC 锚点 href 或自动 slug 规则。
- 不引入新依赖。

## TDD 计划
1. 新增测试：验证 `initTocScrollSpy` 后 TOC 项出现正确层级编号。
2. 新增测试：重复执行编号增强时不重复注入 `.toc-index`。
3. 实现最小代码通过测试。
