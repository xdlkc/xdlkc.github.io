# Spec: 搜索结果点击后自动关闭搜索框

- Date: 2026-03-18 02:35 (Asia/Shanghai)
- Slug: search-auto-close-on-result-click

## 背景 / 问题
当前博客的站内搜索功能中，当用户点击搜索结果链接后，搜索框会保持打开状态。这导致：
- 用户需要额外操作来关闭搜索框
- 页面跳转后，搜索框仍然占据屏幕空间
- 用户体验不够流畅

用户期望点击搜索结果后能直接跳转到目标页面，搜索框自动关闭。

## 需求
为站内搜索添加点击结果后自动关闭搜索框的功能：

### R1. 自动关闭
- 当用户点击搜索结果链接（`.site-search-link`）时，搜索框自动关闭
- 关闭操作在链接跳转之前完成，避免闪烁

### R2. 保留现有功能
- 点击结果链接仍然会记录到最近搜索历史
- 关闭行为与手动关闭按钮一致
- 不影响其他搜索功能（键盘导航、外部链接等）

### R3. 用户体验
- 关闭操作平滑，无延迟
- 不影响链接的正常跳转
- 保持键盘导航的可用性（按 Enter 打开结果，搜索框也会关闭）

## 验收标准
1. 点击搜索结果链接后，搜索框自动关闭
2. 搜索框关闭后，页面能正常跳转到目标页面
3. 最近搜索历史正常记录
4. 键盘导航（Enter 键）打开结果时，搜索框也自动关闭
5. 新增测试文件 `tests/site-search-auto-close-on-result-click.test.js`
6. `npm test` 全部通过

## 边界 / 不做
- 不修改搜索框的其他关闭逻辑（Esc 键、点击遮罩等）
- 不修改搜索结果的排序逻辑
- 不影响移动端的搜索体验
- 不修改搜索框的打开逻辑
