# 打印优化样式

## 功能描述
为博客文章添加打印友好样式，优化文章在打印时的显示效果，使其更美观、更节省纸张。

## 需求
1. **隐藏非必要元素**：打印时隐藏导航栏、侧边栏目录、评论区、搜索按钮、主题切换等
2. **优化正文显示**：
   - 移除深色模式背景，使用白色背景
   - 黑色文字，对比度高
   - 保持代码块样式（保留行号和语法高亮）
   - 图片居中，自动适应页面宽度
3. **优化排版**：
   - 链接在打印时显示 URL
   - 移除多余边距和内边距
   - 页面底部添加来源链接
4. **保留必要信息**：文章标题、作者、发布时间、标签等元数据

## 验收标准
- [ ] 打印预览时不显示导航栏、侧边栏、评论等非必要元素
- [ ] 正文在打印时使用白色背景、黑色文字
- [ ] 代码块在打印时保持可读性（保留语法高亮）
- [ ] 图片在打印时自动缩放，不会超出页面边界
- [ ] 链接在打印时显示完整 URL
- [ ] 页面底部显示文章来源链接
- [ ] 测试通过（或提供测试方案）

## 边界
- 仅在打印模式（@media print）下生效，不影响正常屏幕显示
- 不依赖 JavaScript，纯 CSS 实现
- 保持现有屏幕显示样式不变

## 实现方式
在 `themes/evan/source/css/style.css` 文件末尾添加 `@media print` 媒体查询，覆盖打印时的样式规则。

## 测试方案
1. 使用浏览器打印预览功能（Ctrl/Cmd+P）
2. 检查打印预览中是否隐藏了非必要元素
3. 检查正文样式是否正确
4. 检查代码块、图片是否正常显示
5. 检查链接是否显示 URL
6. 检查页面底部是否有来源链接
