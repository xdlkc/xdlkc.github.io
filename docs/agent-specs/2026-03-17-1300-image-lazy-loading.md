# Spec: 文章图片懒加载（Image Lazy Loading）

- Date: 2026-03-17 13:00 (Asia/Shanghai)
- Slug: image-lazy-loading

## 背景 / 问题
当前博客的文章图片在页面加载时立即加载，对于包含多张图片的长文章，会导致：
- 初始页面加载时间较长
- 不必要的带宽消耗（用户可能不滚动到底部）
- 首屏渲染延迟
- 用户体验不佳

用户期望快速加载页面，图片在滚动到可视区域时才加载。

## 需求
为文章中的所有图片添加懒加载功能：

### R1. 懒加载标记
- 为文章正文中的所有 `<img>` 标签添加 `loading="lazy"` 属性
- 保持现有的 `src`、`alt` 等属性不变
- 支持文章头图、正文图片、相关文章图片等

### R2. 性能优化
- 使用浏览器原生的懒加载 API（`loading="lazy"`）
- 不依赖第三方库
- 不影响页面功能

### R3. 用户体验
- 图片加载时有占位符或背景色
- 图片加载完成后平滑显示
- 不影响 SEO（搜索引擎可以正常爬取图片）

### R4. 兼容性
- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 对于不支持原生懒加载的浏览器，保持原有加载行为

## 验收标准
1. 文章正文中的所有 `<img>` 标签都有 `loading="lazy"` 属性
2. 图片在滚动到可视区域时才开始加载
3. 页面加载时间明显减少（使用 Lighthouse 或浏览器开发者工具验证）
4. 不影响图片的正常显示和功能
5. 不影响文章的其他功能
6. 新增测试文件 `tests/image-lazy-loading.test.js`
7. 新增 JavaScript 文件 `js/image-lazy-loading.js`
8. `layout.ejs` 或 `post.ejs` 引入 `image-lazy-loading.js`
9. `npm test` 全部通过

## 边界 / 不做
- 不实现自定义占位符（使用浏览器默认）
- 不实现图片预加载功能
- 不添加图片加载进度指示器
- 不修改图片本身的样式
- 不影响文章外的图片（如导航栏图片）
