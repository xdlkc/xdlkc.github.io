# Spec: RSS 输出增强（生成 rss.xml 并在导航栏提供入口）

- Date: 2026-03-06 23:34 (Asia/Shanghai)
- Slug: rss-feed

## 需求 / 背景
目前站点没有稳定的 RSS 输出入口，读者无法通过 RSS 阅读器订阅更新。

## 目标
1. 站点构建后在站点根目录生成 `rss.xml`（RSS 2.0）。
2. 站点主导航（首页/文章页/归档页/新闻页/普通页）提供 `RSS` 链接，指向 `/rss.xml`。

## 验收标准（可验证）
- [ ] `npm test` 通过。
- [ ] 测试会触发一次 Hexo generate，并断言输出目录存在 `rss.xml`。
- [ ] `rss.xml` 内容包含 `<rss`，且至少包含一个 `<item`。
- [ ] 以下页面的导航栏都包含 `RSS` 文本链接，且 href 为 `/rss.xml`：
  - 首页（`themes/evan/layout/index.ejs`）
  - 文章页（`themes/evan/layout/post.ejs`）
  - 归档页（`themes/evan/layout/archive.ejs`）
  - 新闻页（`themes/evan/layout/news.ejs`）
  - 普通页面（`themes/evan/layout/page.ejs`）

## 边界 / 不做
- 不新增 Atom/JSON Feed（保持改动小）。
- 不调整 RSS 样式或读者端展示。
- 不引入复杂的分类/标签过滤规则；使用默认 feed 输出逻辑。

## 实现思路
- 安装 `hexo-generator-feed`。
- 在根 `_config.yml` 增加 `feed` 配置，输出 `rss.xml`。
- 在各布局的 nav-links 中新增 `<a href="/rss.xml">RSS</a>`。

## 风险与回滚
- 若生成失败或与现有配置冲突：移除依赖 `hexo-generator-feed` 与 `_config.yml` 的 `feed` 节点即可回滚。
