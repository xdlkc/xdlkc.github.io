# Spec: 站内搜索键盘选择自动滚动可见 (P0/P1: Search UX)

- Date: 2026-03-08 10:34 (Asia/Shanghai)
- Slug: site-search-keyboard-scroll

## 背景 / 问题
站内搜索弹窗支持 ↑/↓ 键选择结果，但当结果列表较长、弹窗内容超出可视区域时：
- 选中的条目可能在可视区域之外；
- 用户需要手动滚动才能看到当前选中项，键盘体验割裂。

## 需求
1. 当用户在站内搜索弹窗中使用 ↑/↓ 改变选中结果时，弹窗的可滚动区域应自动滚动，使 `.site-search-item.is-selected` 始终保持可见（nearest reveal）。
2. 在移动端/小窗口下，搜索结果区域应可滚动（不把页面本身撑高）。

## 验收标准
- [ ] 打开站内搜索（/ 或 Cmd/Ctrl+K），输入关键词得到多条结果。
- [ ] 按 ↓ 多次，选中项滚出可视区域前，弹窗内部会自动滚动，选中项始终可见。
- [ ] CSS 使弹窗主体区域具备 `max-height` + `overflow:auto`，结果过长时在弹窗内部滚动。
- [ ] 单元测试覆盖滚动计算：给定容器高度/scrollTop、itemTop/itemHeight，能计算出期望 nextScrollTop。

## 边界 / 不做
- 不改动搜索排序算法与渲染结构（仅增强键盘导航/滚动）。
- 不引入第三方库。
- 不要求在 jsdom 中真实布局计算；使用纯函数测试滚动计算。
