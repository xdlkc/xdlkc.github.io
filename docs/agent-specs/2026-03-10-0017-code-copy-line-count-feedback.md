# Spec: 代码块复制成功提示展示行数

- 时间：2026-03-10 00:17（Asia/Shanghai）
- 功能名：代码块复制成功提示展示行数

## 需求
当读者点击文章中的代码复制按钮时，除了现有的“复制成功”反馈外，还应明确告诉用户本次复制了多少行代码，让反馈更具体、更可感知。

## 验收标准
1. 点击代码块复制按钮后，成功提示文案包含复制的代码行数，例如“已复制 3 行”。
2. 复制按钮在成功后的短暂反馈态也包含相同的行数信息，例如“已复制（3 行）”。
3. 单行代码应显示为“已复制 1 行”。
4. 失败时仍保持现有失败提示，不显示错误的行数成功文案。
5. 不改变实际复制内容，只增强成功反馈。

## 边界
- 本次只增强点击复制按钮后的反馈，不修改双击复制的交互。
- 行数按复制文本中的换行数计算，忽略末尾多余空行（沿用现有提取逻辑）。
- 不新增复杂国际化系统，先沿用现有中文反馈文案。
