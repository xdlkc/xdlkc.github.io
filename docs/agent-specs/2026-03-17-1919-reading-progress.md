# Spec: Reading Progress Bar

## 需求 (Requirement)
在文章页面（或全局）顶部添加一个阅读进度条，随着用户向下滚动页面，进度条的宽度相应增加，指示当前的阅读进度。

## 验收标准 (Acceptance Criteria)
1. 页面顶部应有一个固定定位（`position: fixed`）的进度条容器。
2. 当页面发生滚动时，通过 JS 计算滚动比例，更新进度条的 `width`。
3. 如果在最顶部，宽度为 0%；在最底部，宽度为 100%。

## 边界与约束 (Boundaries)
- 兼容主流浏览器。
- 无明显性能问题（可以使用简单的 scroll 事件监听，由于是轻量级博客）。
