# Spec: 文章标签 SEO 元信息输出

- 时间：2026-03-06 08:25 (Asia/Shanghai)
- 类型：小功能迭代（SEO）

## 背景
当前页面已输出基础 OG/Twitter 元信息，但文章标签（tags）未输出到 head，导致搜索引擎与社交抓取器无法直接利用文章主题标签。

## 需求
为文章页新增标签元信息输出能力：
1. 在 `social_meta` 结果中增加 `articleTags` 字段；
2. 从 `page.tags` 提取标签名（支持字符串数组与对象数组 `{ name }`）；
3. 去重、去空白，最多输出前 5 个；
4. 在页面 `<head>` 中为每个标签输出一条 `<meta property="article:tag" ...>`；
5. 同时输出 `<meta name="keywords" ...>`，值为逗号分隔标签列表（当有标签时）。

## 验收标准
- `buildSocialMeta` 在文章页可返回规范化后的 `articleTags`；
- 非文章页或无标签时，`articleTags` 为空数组；
- 测试覆盖：
  - 提取对象/字符串混合标签；
  - 去重、trim、上限 5；
  - 无标签时返回空数组；
- 现有测试全部通过。

## 边界与非目标
- 不改动页面正文展示；
- 不引入新依赖；
- 不处理标签同义词归并（仅按字符串精确去重）。
