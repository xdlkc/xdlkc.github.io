# Spec: Site Search 多关键词高亮与更合理的排序

- 时间：2026-03-07 04:34 (Asia/Shanghai)
- 功能名：站内搜索多关键词高亮
- 目标：当用户输入包含空格的多个关键词时，搜索结果能对每个关键词分别高亮，并且排序更符合直觉（匹配更多关键词/标题匹配优先）。

## 用户故事（SDD）

作为读者，我在站内搜索时经常会输入多个关键词（例如“agent world”）。我希望：
1) 结果里标题/标签能把每个关键词都标出来，快速确认命中点；
2) 结果排序能优先展示同时命中更多关键词、且在标题中命中的文章。

## 验收标准

1. 输入框 query 含多个以空格分隔的关键词时：
   - 搜索结果标题内每个关键词都被 `<mark>` 包裹（大小写不敏感）。
   - 标签（tags）同样按关键词逐个高亮。
2. 排序规则：
   - 同时命中多个关键词的文章优先于只命中少数关键词的文章；
   - 标题命中权重大于标签命中；
   - 仍保持稳定的 tie-breaker（按标题字母序）。
3. 兼容性：
   - 单关键词行为与当前保持一致；
   - 不引入 XSS：高亮仍在 escape 后进行。

## 边界 / 非目标

- 不做复杂的分词/中文切词；仅按空白拆分关键词。
- 不实现“必须全部关键词都命中”的严格 AND 过滤（本轮为加权排序）。
- 不改 UI 样式（仅复用现有 `<mark>`）。

## 测试计划（TDD）

- 单测：
  - `highlightText()` 对多关键词 query 能同时高亮多个关键词。
  - `searchPosts()` 对多关键词 query 的排序：命中更多关键词/标题命中优先。
