# 文章页自动 TOC（目录）与锚点导航 [SDD+TDD]

## 需求 (Demand)
在博客文章页面，自动生成一个包含文章内所有标题（H1, H2, H3）的目录 (Table of Contents)。
目录项应可点击，点击后平滑滚动到对应的文章标题位置。
文章标题应具有唯一锚点，以便目录可以链接。

## 验收标准 (Acceptance Criteria)
1.  所有文章页面（`/posts/*`）在侧边栏或文章内容附近显示一个动态生成的目录。
2.  目录应至少包含 H1, H2, H3 级别的标题。
3.  每个目录项都是一个可点击的链接。
4.  点击目录项后，页面应平滑滚动到对应的文章标题。
5.  文章标题（H1, H2, H3）在 DOM 中应具有唯一的 `id` 属性，作为锚点。

## 边界 (Boundaries)
*   仅处理 Markdown 渲染后的 HTML 中的标题元素。
*   不考虑非 Markdown 内容中的标题。
*   初始版本可以不包含高亮和移动设备优化。
*   生成锚点的逻辑需要确保唯一性，例如通过标题文本哈希或序号。
*   需要识别并集成到现有的页面模板或 Markdown 渲染流程中。
