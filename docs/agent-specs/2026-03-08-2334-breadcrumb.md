# Spec: Post breadcrumb navigation + JSON-LD (BreadcrumbList)

Date: 2026-03-08 23:34 (Asia/Shanghai)
Slug: breadcrumb

## Goal / User value
On article pages, show a small breadcrumb navigation (Home → Archives → Current post) so readers can quickly jump back, and add a matching JSON-LD `BreadcrumbList` for richer snippets.

## Non-goals / Boundaries
- No category tree inference (only fixed Home/Archives).
- No changes to permalink structure.
- No global layout rewrite; only post pages.
- No external dependencies.

## Requirements
1. On post pages, render a breadcrumb nav near the title area.
2. Breadcrumb items:
   - Home: `/`
   - Archives: `/archives/`
   - Current post: non-link text (current page title)
3. Note: the theme already renders `BreadcrumbList` JSON-LD globally in `layout.ejs`; this feature focuses on the **visible** breadcrumb UI (no duplicate JSON-LD injection).
4. Should be idempotent: initializing multiple times must not duplicate DOM.

## Acceptance criteria
- On a post page, DOM contains a breadcrumb nav with 3 items and correct links.
- The current post crumb is marked as current (aria-current="page") and is not a link.
- Unit tests cover:
  - breadcrumb item construction
  - DOM rendering/idempotency
