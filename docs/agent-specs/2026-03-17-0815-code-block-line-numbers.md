# Spec: 代码块行号显示

- 时间：2026-03-17 08:15 (Asia/Shanghai)
- 类型：用户体验优化

## 需求
为博客文章中的代码块添加行号显示，提升代码可读性和可引用性，方便用户讨论和引用代码。

## 用户可感知价值
- 代码块左侧显示行号，方便定位代码行
- 复制代码时不包含行号（保持原有复制功能）
- 在暗色模式下也能清晰显示行号
- 移动端也能正常显示行号

## 验收标准
1. 代码块（<pre> 和 <figure.highlight>）左侧显示行号
2. 行号从 1 开始，连续递增
3. 复制代码时不包含行号（保持原有复制功能）
4. 行号样式与代码块主题匹配（亮色/暗色模式）
5. 移动端也能正常显示行号（不影响布局）
6. 行号不参与文本选择（避免误选）
7. 长代码块（超过 100 行）也能正常显示

## 边界与非目标
- 不为行号添加点击跳转功能（保持简单）
- 不添加行号高亮或断点功能（超出范围）
- 不为内联代码（<code>）添加行号
- 不修改代码复制功能的行为
- 不为空的代码块添加行号

## 实现方式
1. 在 `themes/evan/source/js/` 中创建 `code-line-numbers.js`
2. 使用 CSS counter 或 JavaScript 生成行号
3. 在代码块左侧添加一个独立的列用于显示行号
4. 在 `themes/evan/source/css/style.css` 中添加行号样式
5. 在 `post.ejs` 或相关脚本中初始化功能
