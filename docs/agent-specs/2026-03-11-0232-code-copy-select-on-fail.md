# Spec: 复制失败时自动选中代码，方便手动复制

- 日期时间：2026-03-11 02:32 (Asia/Shanghai)
- 目标：当“复制代码”按钮点击后由于权限/浏览器限制导致复制失败时，自动选中对应代码块内容，并给出明确提示，降低用户挫败感。

## 需求 / 用户故事

作为读者，当我点击代码块右上角的“复制代码”按钮但复制失败时，我希望页面能自动选中代码内容，这样我可以直接按 Ctrl/Cmd+C 手动复制，而不用自己拖拽选择。

## 验收标准

1. 当点击 `.code-copy-button` 触发复制，若 `navigator.clipboard.writeText` 或 fallback 复制流程抛错：
   - 页面会自动选中该代码块的代码文本（`<pre><code>` 优先选中 `code`，highlight 选中 `.code` 容器）。
   - toast 文案仍为现有的失败提示（中/英文随语言模式）。
2. 复制成功时行为保持不变：toast + 高亮 flash + 按钮临时显示已复制（行数）。
3. 自动选中逻辑应尽量健壮：无 Selection API 时不报错；重复点击不会导致异常。

## 边界 / 非目标

- 不引入新的 UI 控件；不改变成功路径文案。
- 不尝试绕过浏览器权限策略（仅提供“选中以便手动复制”的降级）。
- 不改变双击复制(dblclick)的行为（本次仅覆盖按钮点击失败分支）。

## 测试策略 (TDD)

- 新增单元测试：模拟 `navigator.clipboard.writeText` 抛错，验证：
  - toast 显示失败文案
  - `window.getSelection().toString()` 含有代码内容（证明已被选中）
