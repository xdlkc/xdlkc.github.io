# Spec: 文章页自动 TOC（目录）与锚点导航

## 需求
在博客文章页面，自动生成一个可点击的目录（Table of Contents, TOC），TOC应包含文章中所有H2和H3标题，并为这些标题添加锚点，点击TOC中的链接可平滑滚动到对应标题。

## 验收标准
1.  **自动生成TOC**:
    *   在每篇文章的指定位置（例如，侧边栏或文章内容上方）自动渲染一个TOC。
    *   TOC应包含文章中的H2和H3标题。
    *   TOC结构应反映标题层级（H2为一级，H3为二级）。
2.  **锚点导航**:
    *   文章中的H2和H3标题应自动生成唯一的ID作为锚点。
    *   TOC中的每个链接都应指向对应的标题锚点。
    *   点击TOC链接后，页面应平滑滚动到对应标题。
3.  **用户感知**:
    *   用户在阅读文章时能清晰看到TOC，并能方便地通过TOC进行导航。
    *   TOC应在文章内容足够长时才显示（例如，至少有3个H2/H3标题）。

## 边界
1.  **标题级别**: 仅处理H2和H3标题。
2.  **位置**: 初步考虑将其放置在文章内容的左侧或右侧边栏（如果主题支持）或文章顶部。具体位置需根据主题布局确定。
3.  **样式**: TOC的样式应与现有博客主题保持一致，或提供基础样式以便后续美化。
4.  **动态内容**: 仅处理初始页面加载时的静态HTML内容，不考虑通过JavaScript动态加载的标题。
5.  **实现方式**: 优先考虑使用Liquid模板语言或少量JavaScript实现，避免引入大型库。
