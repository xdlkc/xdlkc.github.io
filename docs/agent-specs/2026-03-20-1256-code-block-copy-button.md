# 功能规格：代码块复制按钮与复制成功提示

## 需求

在文章页面中的每个代码块（`<pre><code>...</code></pre>`）上方或右上方，添加一个可点击的“复制”按钮。当用户点击此按钮时，代码块内的所有文本内容应被复制到剪贴板。复制成功后，按钮文本或旁边应显示一个临时的“已复制！”提示，并在短暂时间后恢复原状。

## 验收标准

1.  **复制按钮存在:**
    *   在每个 `<pre><code>` 代码块的可见区域内，存在一个“复制”按钮。
    *   按钮应具有清晰的视觉标识（例如，图标或文本“复制”）。
2.  **功能性复制:**
    *   点击“复制”按钮，应将对应代码块的纯文本内容复制到用户的剪贴板。
    *   复制的内容不应包含行号、高亮标记或其他非代码文本。
3.  **成功提示:**
    *   成功复制后，“复制”按钮的文本应暂时变为“已复制！”或在附近显示一个“已复制！”的提示。
    *   提示应在2-3秒后自动消失，按钮恢复到初始状态。
4.  **无副作用:**
    *   复制操作不应影响页面的其他功能或布局。
    *   在不支持 `navigator.clipboard.writeText` 的浏览器中，应优雅降级（例如，按钮无功能或显示提示“浏览器不支持复制”）。
5.  **跨浏览器兼容性:**
    *   在主流浏览器（Chrome, Firefox, Safari, Edge）中测试功能。

## 边界条件

*   **空代码块:** 如果代码块内没有内容，复制按钮不应报错，点击后应复制空字符串。
*   **长代码块:** 确保长代码块的内容也能完整复制。
*   **代码高亮:** 复制功能不应干扰现有的代码高亮样式。
*   **CSS/JS 侵入性:** 尽量减少对现有CSS和JS的侵入性修改，以保持项目结构清晰。
