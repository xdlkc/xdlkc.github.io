# Spec: TOC 目录项一键复制锚点链接（TOC Link Copy）

- Date: 2026-03-11 11:28 (Asia/Shanghai)
- Slug: toc-link-copy

## 背景
文章页已有标题处的「复制锚点」能力，但用户在阅读时更多是从目录（TOC）定位章节。
希望在目录里就能一键复制对应章节链接，用于分享/笔记引用。

## 需求
在文章页/页面的目录（`.toc-nav`，包含移动端与桌面端）中：

- 为每个目录项链接 `a[href^="#"]` 注入一个「复制」按钮（例如图标或短文本）。
- 点击按钮后复制“当前页面完整 URL + 该目录项 hash”（例如 `https://xdlkc.github.io/2026/.../#section`）。
- 复制成功给出 toast 提示：
  - 中文：`已复制目录链接`
  - 英文：`Copied TOC link`
- 复制失败时 toast 提示：
  - 中文：`复制失败，请手动复制`
  - 英文：`Copy failed, please copy manually`

## 验收标准
- 点击任一目录项的复制按钮，会调用 `navigator.clipboard.writeText`（或 fallback）并写入包含对应 hash 的 URL。
- 幂等：重复初始化不会重复注入按钮。
- 不改变目录项原有点击跳转行为（复制按钮应 `stopPropagation`/`preventDefault`，不触发跳转）。
- 移动端与桌面端 TOC 都生效。

## 边界 / 不做
- 不对非 hash 链接（不以 `#` 开头）注入复制按钮。
- 不对没有 `id` 的目标标题做修复（已有 TOC 修复逻辑负责）。
- 不做复杂权限/用户引导；失败仅提示。
