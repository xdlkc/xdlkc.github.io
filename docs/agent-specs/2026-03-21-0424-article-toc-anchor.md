# 文章页自动 TOC（目录）与锚点导航

## 需求 (Requirement)
在博客文章页面，根据文章中的 H2 和 H3 标题自动生成可点击的目录 (Table of Contents)，并为每个标题添加锚点链接，实现点击目录项后平滑滚动到对应标题位置的功能。

## 验收标准 (Acceptance Criteria)
1.  **TOC 显示:** 任何博客文章页面加载时，应在页面侧边栏或文章内容区域的特定位置显示一个自动生成的目录。
2.  **标题层级:** 目录应只包含文章内的 H2 和 H3 标题。
3.  **可点击导航:** 目录中的每个条目都应是可点击的链接。
4.  **平滑滚动:** 点击目录项后，页面应平滑滚动到对应的文章标题位置。
5.  **锚点链接:** 文章中的每个 H2 和 H3 标题都应自动生成唯一的 ID，并显示一个可点击的锚点图标或链接（例如，在标题悬停时显示），点击该图标可以直接复制带锚点的 URL 或直接跳转。
6.  **URL 更新:** 点击目录或锚点链接后，浏览器的 URL 应更新为包含对应锚点哈希值（例如 `#/section-title`）。

## 边界 (Boundaries)
1.  **标题深度:** 仅处理 H2 和 H3 标题。H1 通常是文章标题，不应包含在 TOC 中；H4 及以下层级不包含在 TOC 中。
2.  **排除特定标题:** 可以通过给标题添加特定 CSS class (例如 `no-toc`) 来选择性地排除某些标题不出现在目录中。
3.  **初始实现:** 首次迭代主要关注功能实现，基本样式即可，无需过度美化。后期可迭代优化样式和交互。
4.  **技术栈:** 基于现有 Hexo/Jekyll 模板引擎和 JavaScript 实现。
