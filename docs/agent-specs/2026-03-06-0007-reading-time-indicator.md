# Spec: 文章阅读时长提示（Reading Time Indicator）

## 背景
文章页当前仅展示发布日期，读者无法快速预估阅读成本。新增“预计阅读时长”可提升点击后的阅读预期与体验。

## 需求
在文章详情页（post）标题下方元信息中，新增预计阅读时长展示：`预计阅读 X 分钟`。

## 验收标准
1. 文章页元信息显示格式：`发布于 YYYY-MM-DD · 预计阅读 X 分钟`。
2. 阅读时长按内容长度估算，规则：
   - 中文字符：300 字/分钟
   - 英文单词：200 词/分钟
   - 混合内容可叠加后向上取整。
3. HTML 标签不计入字数/词数。
4. 空内容或无法统计内容时，最小显示 1 分钟。
5. 不影响现有 canonical URL 与页面结构功能。

## 边界与非目标
- 不做逐段精确阅读模型（如代码块权重、图片权重）。
- 不在首页卡片展示阅读时长，仅文章详情页展示。
- 不引入第三方依赖。
