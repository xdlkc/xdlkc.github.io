# 暗色模式记忆功能

## 需求 (Requirement)

为博客添加暗色模式切换功能，并记住用户的选择。用户点击切换按钮后，网站应切换到相应的主题（亮色/暗色），并且在下次访问时自动恢复到上次选择的主题。

## 验收标准 (Acceptance Criteria)

1. **添加主题切换按钮**：
   - 在页面的固定位置（例如右上角）添加一个可见的主题切换按钮
   - 按钮应显示当前主题的图标（例如太阳表示亮色模式，月亮表示暗色模式）
   - 按钮位置应在移动端和桌面端都易于访问

2. **主题切换功能**：
   - 点击按钮时，在亮色和暗色模式之间切换
   - 切换时，更新 `<html>` 或 `<body>` 元素的 `data-theme` 属性（"light" 或 "dark"）
   - 切换时，按钮图标应相应更新
   - 切换时，可以添加平滑的过渡动画（可选）

3. **主题记忆功能**：
   - 使用 `localStorage` 存储用户选择的主题
   - 存储键名：`theme-preference`（或类似名称）
   - 存储值：`"light"` 或 `"dark"`
   - 当用户切换主题时，立即保存到 localStorage
   - 页面加载时，从 localStorage 读取并应用保存的主题
   - 如果 localStorage 中没有保存的主题，则使用默认主题（亮色）

4. **系统偏好检测（可选但推荐）**：
   - 如果用户没有保存的主题偏好，检测系统是否为暗色模式
   - 使用 `window.matchMedia('(prefers-color-scheme: dark)')` 检测
   - 如果系统是暗色模式，则应用暗色主题

5. **CSS 变量支持**：
   - 确保暗色模式的 CSS 变量已定义（已在 `css/main.css` 中存在）
   - 主题切换后，所有相关样式应立即应用

## 边界 (Boundaries)

- 此功能仅关注前端主题切换和记忆，不涉及后端存储
- 不需要实现动态加载主题文件
- 不需要实现主题预览或主题商店功能
- 确保在 JavaScript 加载失败时，页面仍然可用（回退到默认主题）
- 考虑禁用 JavaScript 的情况（虽然在这个项目中，JavaScript 是必需的）

## 技术实现要点

1. **按钮 HTML**：可以在现有的主题布局中添加按钮（例如在导航栏或工具栏）
2. **JavaScript 逻辑**：
   - 从 localStorage 读取主题偏好
   - 如果没有，检测系统偏好
   - 应用主题（设置 `data-theme` 属性）
   - 更新按钮图标
   - 监听点击事件，切换主题并保存
3. **CSS**：已经存在 `[data-theme="dark"]` 的样式，确保覆盖足够全面

## 测试要点

1. 点击切换按钮，验证主题切换
2. 验证按钮图标更新
3. 验证 localStorage 中保存了正确的主题值
4. 刷新页面，验证主题被恢复
5. 验证系统偏好检测（可选）
6. 验证 CSS 变量在主题切换后正确应用
