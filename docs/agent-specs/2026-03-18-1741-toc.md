# Spec: Automatic TOC and Anchor Navigation

## Description
Auto-generate a Table of Contents (TOC) with anchor navigation for all post pages.

## Acceptance Criteria
1. For pages with layout `post`, prepend a `<div class="post-toc">` containing the `toc(data.content)` if headings exist.
2. The generated TOC must contain links corresponding to the post's markdown headings.
3. Tests must verify the TOC HTML is correctly injected into `post` layout contents.

## Boundaries
- Do not inject TOC into non-post layouts (e.g., page, index).
