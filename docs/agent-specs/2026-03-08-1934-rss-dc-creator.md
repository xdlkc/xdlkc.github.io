# Spec: RSS feed inject dc:creator for each item

- Date: 2026-03-08 19:34 (Asia/Shanghai)
- Slug: rss-dc-creator

## 背景 / 问题
当前站点的 `rss.xml` 由 `hexo-generator-feed` 生成，但部分 RSS 阅读器/聚合器在展示条目时会优先使用 `dc:creator`（Dublin Core）字段来展示作者。

目前 feed 中未稳定包含 `dc:creator`，导致一些阅读器里作者信息缺失或展示不一致。

## 目标
在不改动文章源内容的前提下，在生成后的 `rss.xml` 中：
- 确保根节点包含 `xmlns:dc="http://purl.org/dc/elements/1.1/"` 命名空间（若缺失则补上）
- 确保每个 `<item>` 内包含一个 `<dc:creator><![CDATA[...]]></dc:creator>`
  - 内容优先使用 `hexo.config.author`
  - 若 `author` 缺失则不注入（保持原样）
  - 若 `<dc:creator>` 已存在则不重复注入

## 验收标准
1. 运行 `npm test` 通过（新增测试覆盖：
   - 能为 rss 根节点补上 dc namespace
   - 能为 item 补上 dc:creator
   - 已存在 dc:creator 时保持幂等）
2. 构建阶段通过 `after_generate` filter 对 `hexo.route` 的 `rss.xml` 内容做最小变更注入
3. 对非 RSS 路由不产生影响

## 边界 / 非目标
- 不引入 XML 解析依赖（使用可维护的、保守的字符串处理）
- 不尝试注入 per-post author（只使用站点 author）
- 不修改 Atom feed（当前配置为 rss2）
