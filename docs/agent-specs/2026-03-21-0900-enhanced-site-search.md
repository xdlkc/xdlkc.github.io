# 站内搜索增强（标题/标签高亮、无结果建议） [SDD+TDD]

## 需求 (Demand)
增强博客的站内搜索功能，提供更优质的用户体验，具体包括在搜索结果的标题和标签中高亮显示搜索词，并在没有搜索结果时提供有用的建议。

## 验收标准 (Acceptance Criteria)
1.  当用户进行搜索并显示结果时，搜索查询词应在匹配的文章标题和标签中高亮显示。
2.  当用户进行搜索且未找到任何结果时，应显示“无结果”消息，并提供有用的建议（例如，“尝试搜索热门标签”、“检查您的拼写”或“浏览归档”）。
3.  “无结果”建议应可点击，并能触发新的搜索或导航到相关页面（例如，标签页面、归档页面）。

## 边界 (Boundaries)
*   高亮显示应不区分大小写。
*   无结果时的初始建议可以是静态链接，指向一般区域（例如，`/tags/`，`/archives/`）。
*   专注于客户端 JavaScript 增强。假设搜索索引数据（如果存在）已可用。
