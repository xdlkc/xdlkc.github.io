# 文章页自动 TOC（目录）与锚点导航

## 需求
在博客文章页面，自动生成文章内容的目录（Table of Contents），并为每个标题（H2, H3, H4）添加锚点，实现点击目录项平滑滚动到对应内容区域的功能。

## 验收标准
1.  **自动生成目录:**
    *   在文章页的侧边栏或特定区域显示文章的目录。
    *   目录应包含文章中所有 H2、H3、H4 标签。
    *   目录结构应反映标题层级（H2 为一级，H3 为二级，H4 为三级）。
2.  **锚点导航:**
    *   每个目录项点击后，页面应平滑滚动到对应的文章标题位置。
    *   文章标题（H2, H3, H4）应被赋予唯一的 ID，作为锚点链接的目标。
    *   当用户滚动页面时，当前在视口中的标题对应的目录项应有高亮显示。
3.  **用户体验:**
    *   目录应是可折叠/展开的（可选，如果实现成本不高）。
    *   目录在移动端或其他小屏幕设备上应能自动隐藏或变为可点击的浮动按钮。
4.  **技术实现:**
    *   应使用 JavaScript 在客户端动态生成目录。
    *   避免对现有 Markdown 解析器或渲染流程进行侵入性修改，优先通过 DOM 操作实现。

## 边界
*   目前仅支持文章页，非文章页不应出现目录。
*   不考虑目录持久化（例如用户关闭页面后目录状态的保存）。
*   目录样式应与博客现有主题风格保持一致或最小化影响。
*   锚点 ID 生成应考虑唯一性，避免冲突。
