# 功能规格：文章页自动 TOC（目录）与锚点导航

## 需求 (Requirement)
在博客文章页面中，自动生成文章的目录 (TOC)，并提供锚点导航功能。

## 验收标准 (Acceptance Criteria)
1. **自动生成目录**: 文章页面加载后，侧边栏（或指定位置）应显示一个可折叠的目录。
2. **内容来源**: 目录应根据文章内容中的 `H2`, `H3` 标签自动生成。
3. **锚点导航**: 目录中的每个条目都应是可点击的链接，点击后平滑滚动到对应的标题位置。
4. **高亮显示**: 页面滚动时，目录中当前可见的标题对应的条目应有高亮显示。
5. **空目录处理**: 当文章中没有 `H2`/`H3` 标题时，目录不显示。
6. **响应式设计**: 目录应具有响应式设计，在小屏幕上可隐藏或以其他方式展示。

## 边界 (Boundaries)
1. **标签范围**: 仅处理 Markdown 渲染后的 HTML 中的 `H2` 和 `H3` 标签。不处理 `H1` 标签。
2. **样式集成**: 目录的样式与位置应与博客现有主题兼容，但可以进行初步的默认样式。
3. **配置性**: 初始版本不考虑目录的嵌套深度可配置性。
4. **浏览器兼容性**: 兼容主流现代浏览器（Chrome, Firefox, Safari, Edge 最新版本）。
