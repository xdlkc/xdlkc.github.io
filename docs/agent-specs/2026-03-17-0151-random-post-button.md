# 随机文章按钮

## 需求描述

在博客中添加随机文章按钮，点击后随机跳转到一篇文章，帮助用户发现更多内容，增加内容探索的乐趣。

## 功能范围

### 核心功能

1. **随机文章按钮**
   - 在导航栏或侧边栏添加随机文章按钮
   - 点击按钮时从所有文章中随机选择一篇
   - 跳转到选中的文章页面
   - 支持中英文模式（按钮文本自动切换）

2. **文章筛选**
   - 只从已发布的文章中选择（排除草稿）
   - 确保不是当前所在的文章（避免随机到自己）
   - 优先选择带有标签的文章（提高质量）

### 边界条件

1. **文章数量**
   - 如果只有1篇文章，不显示按钮或禁用按钮
   - 如果有0篇文章，不显示按钮
   - 当前文章是唯一文章时，跳转到首页

2. **移动端适配**
   - 移动端和桌面端都可用
   - 按钮大小适配不同屏幕

3. **无障碍访问**
   - 按钮有合适的 aria-label
   - 支持键盘操作（Tab 键可聚焦，Enter/Space 可触发）

## 验收标准

1. 导航栏中正确显示随机文章按钮
2. 点击按钮，浏览器跳转到随机一篇文章
3. 不会随机跳转到当前所在的文章
4. 中英文模式下按钮文本正确切换
5. 按钮支持键盘操作（Tab + Enter/Space）
6. 如果没有可用的文章，按钮不显示或禁用

## 实现细节

### HTML 结构

```html
<button class="random-post-button" data-random-post aria-label="Random post">
  <span data-i18n-key="nav.random">Random</span>
</button>
```

### 数据结构

- 使用 Hexo 的 `site.posts` 获取所有文章
- 过滤条件：已发布、不是当前文章

### JavaScript 逻辑

1. 获取所有文章列表（从 `data-posts` 属性或 API）
2. 过滤掉当前文章
3. 从剩余文章中随机选择一篇
4. 构造文章 URL 并跳转

### UI 元素

- `[data-random-post]` - 随机文章按钮
- `.random-post-button` - 按钮样式类
- `[data-i18n-key="nav.random"]` - 国际化文本

### 优先级

- P0: 核心随机跳转功能
- P1: 按钮样式优化
- P2: 高级筛选（如按分类随机）

## 不包含的功能

- 记住用户喜欢的文章
- 基于用户偏好的智能推荐
- 批量随机浏览模式
