# Spec: 文章标签显示

- Date: 2026-03-19 05:27 (Asia/Shanghai)
- Feature slug: post-tags-display

## 背景 / 问题
当前博客文章页面在文章元信息区域只显示发布日期、字数统计和阅读时间，但没有显示文章标签。读者无法快速了解文章的主题标签，也无法方便地点击标签浏览相关文章。

许多博客都会在文章元信息中显示标签列表，这有助于：
- 快速了解文章的主题分类
- 方便点击标签浏览相关文章
- 提升博客的导航体验

## 需求
为博客文章页面添加标签显示：

### R1. 标签显示位置
- 在文章元信息区域显示（与发布日期、字数、阅读时间同一行或下一行）
- 位置：在阅读时间之后，换行显示

### R2. 标签显示格式
- 每个标签显示为一个链接
- 标签链接指向对应的标签页面
- 标签之间用空格分隔
- 标签文本格式：小写、连字符分隔（如 "tech", "web-development"）

### R3. 标签样式
- 标签链接使用简单的文本链接样式
- 颜色：使用主题色或浅色
- 鼠标悬停：下划线或颜色变化
- 不使用特殊的标签徽章样式（保持简洁）

### R4. 无标签处理
- 如果文章没有标签，不显示标签区域
- 如果标签列表为空，不显示标签区域

### R5. 可访问性
- 标签链接添加适当的 `aria-label` 属性
- 标签区域添加 `aria-label="Tags"`
- 保持语义化

### R6. 国际化支持
- 标签显示不需要特殊翻译（标签名称本身不翻译）
- 如果需要，可以添加标签区域的标签（如 "Tags"）

## 验收标准
1. 文章有标签时，在文章元信息区域显示标签列表
2. 每个标签都是可点击的链接，指向对应的标签页面
3. 文章没有标签时，不显示标签区域
4. 标签显示位置正确（在阅读时间之后）
5. 标签链接正确指向标签页面
6. 标签显示格式正确（文本链接，空格分隔）
7. 新增测试文件 `tests/post-tags-display.test.js`
8. `npm test` 全部通过

## 边界 / 不做
- 不修改标签页面的样式
- 不添加标签云或其他标签相关功能
- 不支持自定义标签样式（保持简洁）
- 不支持标签的显示顺序控制

## 技术细节

### 文件变更
- `themes/evan/layout/post.ejs` - 在文章元信息区域添加标签显示

### 实现逻辑
1. 检查文章是否有标签：`page.tags && page.tags.length > 0`
2. 如果有标签，遍历标签列表
3. 每个标签生成一个链接：`<a href="<%- url_for(tag.path) %>"><%- tag.name %></a>`
4. 标签之间用空格分隔
5. 将标签列表添加到文章元信息区域

### 风险
- 低风险：只添加显示功能，不影响现有行为
- 标签链接生成可能需要适配 Hexo 的标签路由

### 示例代码
```ejs
<% if (page.tags && page.tags.length > 0) { %>
  <div class="article-meta-tags" aria-label="Tags">
    <span class="article-meta-sep">·</span>
    <% page.tags.forEach(function(tag, index) { %>
      <a class="article-meta-tag" href="<%- url_for(tag.path) %>" aria-label="Tag: <%= tag.name %>"><%- tag.name %></a><% if (index < page.tags.length - 1) { %> <% } %>
    <% }); %>
  </div>
<% } %>
```

### 显示效果示例
```
Published 2026-03-19 · 3,245 字 · 12 分钟阅读
· tech web-development hexo
```
