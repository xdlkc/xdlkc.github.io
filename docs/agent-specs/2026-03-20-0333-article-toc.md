# Spec: 文章页自动 TOC（目录）与锚点导航

## 需求 (Requirements)
在博客文章页面，自动生成一个侧边目录（Table of Contents），展示文章内的所有标题（H1-H4）。
点击目录项可以平滑滚动到对应的文章内容区域。
目录项应自动高亮显示当前阅读的章节。

## 验收标准 (Acceptance Criteria)
1.  **自动生成目录**:
    *   在文章页面侧边栏（或预定义位置），存在一个可折叠的目录区域。
    *   目录内容应根据文章内的 H1, H2, H3, H4 标签自动生成。
    *   目录结构应反映标题的层级关系（例如，H2嵌套在H1下）。
    *   对于没有 H1-H4 标题的文章，目录区域可以不显示或显示为空。
2.  **锚点导航**:
    *   每个生成的目录项都应是可点击的链接。
    *   点击目录项后，页面应平滑滚动到对应的文章标题位置。
    *   文章中的每个 H1-H4 标题应自动添加唯一的 ID 作为锚点。
3.  **当前章节高亮**:
    *   当用户滚动页面时，目录中当前在视口内的章节标题对应的目录项应自动高亮显示。
    *   高亮状态应随滚动实时更新。
4.  **边界条件**:
    *   确保在不同浏览器和设备上（桌面/移动）基本可用。
    *   性能影响最小化，不显著增加页面加载时间或导致卡顿。
    *   兼容现有的博客主题样式，或提供基本的、可自定义的样式。

## 边界 (Boundaries)
*   不涉及文章内容的动态编辑功能。
*   不涉及目录项的拖拽排序或自定义隐藏。
*   默认不处理超过 H4 的标题。
*   初期不考虑多语言支持。
*   样式调整以功能实现为主，美化可作为后续迭代。
