嗨，欢迎收听本期的技术精读。今天咱们来拆 DeepSeek Harness。它像一套什么都能插拔的 Coding Agent，真正棘手的却是插件怎么活着、怎么隔离，以及模型下一轮如何确认刚刚发生过什么。

先说边界。这是一份非官方研究，结论钉在 0.1.0 的 rc.5 固定快照上。面对 12,293 次可达提交，作者追着删除、重构和回滚，反推设计为何变成今天这样。

把系统想成两只钟，会容易很多。上半边是活着的现在，Cordis 管服务、事件和销毁；下半边是发生的过去，Session Event Log 记录模型看过什么、工具做过什么。中间的 Agent Loop 像调度员，把两边拼成下一步。

Profile 和 Bundle 不是普通配置文件，而像一套小型装配语言。稳定的行 ID 决定插件身份，patch 按顺序覆盖，插件树最后长成 Web、headless 或别的产品形态。入口很薄，产品形态却能变化。

这里有个实用细节：patch 给出 config 时会整块替换，不做深度合并。每层改了什么，都能沿稳定 ID 查回去。但 Loader 会执行本地 JavaScript，所以 Profile 只能当受信任代码，不能当低权限数据。

Cordis 最容易被误解成普通依赖注入容器。其实 Context 还带着 realm、调用者和 Fiber 父子关系；同名服务若要隔离，不是后注册覆盖，而是换作用域。这正是多 Agent 共进程又不互相串味的底座。

每次创建插件都会生成一根 Fiber。服务、监听器、子插件和自建资源都登记成 effect，卸载时从同一个所有者手里收回。热更新则像补偿事务，新插件失败后恢复旧配置、尝试重启，而不是假装从未发生。

Agent Scope 补上另一个问题：同一进程里的 Agent A，为什么不能看见 Agent B 的 persona 和工具？它给共享注册表套了一层按 Agent 解析的视图，让共享基础设施和局部能力同时成立。

妙处是，可见性和清理由同一个 Context 负责，注册工具时不用再手写 scope 加 owner 两个参数。少一个字段，就少一种配错。不过它仍是逻辑隔离，不是操作系统沙箱，插件照样能访问进程资源。

Agent Loop 也不是 while 工具调用还有没有，而是一条可取消、可恢复的行动链。一轮用户目标是 turn，同一轮里每次模型请求是 step；工具结果回来后不新开 turn，只进入下一个 step。

每一步都从日志重新派生请求历史。系统提示和工具 schema 按当前 Scope 在发送前组装，真实发送值写进 request header，恢复时不用猜配置。工具可以并行跑，结果却要按模型调用顺序提交，否则重放会漂移。

流式 chunk 只是过程证据，最终 assistant message 才是下一轮读取的事实。两者都能进日志，却不能混成同一种东西。Session append 的提交线也很清楚：提交前失败，日志不变；提交后观察者报错，只记警告，不能撤回事实。

持久化默认走约两百毫秒的批量写后队列，但这不是最多丢两百毫秒的保证。需要耐久时必须显式 flush，关键副作用前也要设屏障。模型 Surface 只是日志的一种读法，压缩可以遮住旧节点，原始证据仍留着。

恢复时，系统不会替用户瞎猜副作用。调用已记录却结果不明，就写 TOOL_OUTCOME_UNKNOWN；还没开始，就写 TOOL_NOT_STARTED，再闭合中断的 turn。Host 也统一折叠标题、待办等界面状态，避免客户端再算一份。

Tool 和 LLM 的拆法很克制：定义、模型看到的投影、底层 provider 分开。换本地 Bash 不必改模型 schema，换工具文案也不必污染进程接口。这种边界让差异留在适配层，Loop 才不用长出 provider 分支。

并发安全必须由工具显式声明，默认全部独占，因为 Runtime 无法证明第三方工具没有共享状态。LLM 适配器也被迫统一流式协议，连回复被 token 截断时丢弃全部工具调用，这种保守选择都能自然表达。

再看 12,293 次提交，真正值得看的不是数量，而是删除。瞬态事件镜像被删，通用 Mode 退回专用 Plan Mode，客户端领域计算被收回 Host。成熟的标志不是抽象越多越好，而是发现重复事实后敢撤回实现。

文档也像工程系统。CI 会检查生成目录、类型等价、双语新鲜度、链接和 Mermaid，五百多份 Agent Note 记录设计取舍。机器能发现结构腐烂，却看不懂自然语言里的旧假设，所以仍需要对抗审查。

如果独立开发者只有一两个人，最该先借四件事：单一事实源，并行执行但顺序提交，注册与清理绑定，再拿两个真实 Provider 压接口。只接一个 SDK 时，所谓通用接口很容易只是给它的方法改了名字。

Scope、Bundle 和完整微内核先别急着搬。等真的出现 Web 之外的第二种产品形态，再抽公共插件树。配置语言会同时带来身份、覆盖顺序、兼容和安全责任，不是为了架构感提前搭一座城堡。

所以，这篇研究最值得带走的，不是二十三万行代码，而是那句所有权问题：这项状态到底由谁拥有？Cordis 让能力活起来，Session Log 让事实留下来，Agent Loop 只是诚实地把两者接起来。
